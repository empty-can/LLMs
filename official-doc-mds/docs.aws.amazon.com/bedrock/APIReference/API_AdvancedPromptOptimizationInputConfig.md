

# AdvancedPromptOptimizationInputConfig
<a name="API_AdvancedPromptOptimizationInputConfig"></a>

The input data configuration for an advanced prompt optimization job.

 ** s3Uri **   <a name="bedrock-Type-AdvancedPromptOptimizationInputConfig-s3Uri"></a>
The S3 URI of the input JSONL file.  
Type: String  
Length Constraints: Minimum length of 1. Maximum length of 1024.  
Pattern: `s3://[a-z0-9][-.a-z0-9]{1,61}[a-z0-9](?:/[-!_*'().a-z0-9A-Z]+(?:/[-!_*'().a-z0-9A-Z]+)*)?/?`   
Required: Yes
