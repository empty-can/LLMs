

# AutomatedReasoningCheckInputTextReference
<a name="API_AutomatedReasoningCheckInputTextReference"></a>

## Contents
<a name="API_AutomatedReasoningCheckInputTextReference_Contents"></a>

 ** text **   <a name="bedrock-Type-AutomatedReasoningCheckInputTextReference-text"></a>

Type: String  
Length Constraints: Minimum length of 0. Maximum length of 1000.  
Required: No
