

# S3ObjectFile
<a name="API_agent-runtime_S3ObjectFile"></a>

Contains details of the s3 object where the source file is located.

## Contents
<a name="API_agent-runtime_S3ObjectFile_Contents"></a>

 ** uri **   <a name="bedrock-Type-agent-runtime_S3ObjectFile-uri"></a>
The uri of the s3 object.  
Type: String  
Length Constraints: Minimum length of 1. Maximum length of 1024.  
Pattern: `s3://[a-z0-9][a-z0-9.-]{1,61}[a-z0-9]/.{1,1024}`   
Required: Yes
