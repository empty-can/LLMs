

# AdvancedPromptOptimizationOutputConfig
<a name="API_AdvancedPromptOptimizationOutputConfig"></a>

The output data configuration for an advanced prompt optimization job.

## Contents
<a name="API_AdvancedPromptOptimizationOutputConfig_Contents"></a>

 ** s3Uri **   <a name="bedrock-Type-AdvancedPromptOptimizationOutputConfig-s3Uri"></a>
The S3 URI prefix for the output location.  
Type: String  
Length Constraints: Minimum length of 1. Maximum length of 1024.  
Pattern: `s3://[a-z0-9][-.a-z0-9]{1,61}[a-z0-9](?:/[-!_*'().a-z0-9A-Z]+(?:/[-!_*'().a-z0-9A-Z]+)*)?/`   
Required: Yes
