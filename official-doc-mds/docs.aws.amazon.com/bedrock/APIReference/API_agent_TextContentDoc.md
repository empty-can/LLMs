

# TextContentDoc
<a name="API_agent_TextContentDoc"></a>

 ** data **   <a name="bedrock-Type-agent_TextContentDoc-data"></a>

Type: String  
Length Constraints: Minimum length of 1. Maximum length of 5242880.  
Required: Yes
