

# AgenticRetrieveActionDetails
<a name="API_agent-runtime_AgenticRetrieveActionDetails"></a>

Required: Yes

 ** sourceRetrievers **   <a name="bedrock-Type-agent-runtime_AgenticRetrieveActionDetails-sourceRetrievers"></a>
The list of source retrievers targeted by this action.  
Type: Array of [AgenticRetrieveSourceRetriever](API_agent-runtime_AgenticRetrieveSourceRetriever.md) objects  
Required: Yes
