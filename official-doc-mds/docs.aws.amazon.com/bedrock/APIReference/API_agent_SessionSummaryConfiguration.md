

# SessionSummaryConfiguration
<a name="API_agent_SessionSummaryConfiguration"></a>

Configuration for SESSION\_SUMMARY memory type enabled for the agent.

## Contents
<a name="API_agent_SessionSummaryConfiguration_Contents"></a>

 ** maxRecentSessions **   <a name="bedrock-Type-agent_SessionSummaryConfiguration-maxRecentSessions"></a>
Maximum number of recent session summaries to include in the agent's prompt context.  
Type: Integer  
Valid Range: Minimum value of 1.  
Required: No
