

# ImageExtractionConfiguration
<a name="API_agent_ImageExtractionConfiguration"></a>

Configuration for image extraction.

## Contents

 ** imageExtractionStatus **   <a name="bedrock-Type-agent_ImageExtractionConfiguration-imageExtractionStatus"></a>
Whether image extraction is enabled or disabled.  
Type: String  
Valid Values: `ENABLED | DISABLED`   
Required: Yes
