

# RerankTextDocument
<a name="API_agent-runtime_RerankTextDocument"></a>

Contains information about a text document to rerank.

## Contents
<a name="API_agent-runtime_RerankTextDocument_Contents"></a>

 ** text **   <a name="bedrock-Type-agent-runtime_RerankTextDocument-text"></a>
The text of the document.  
Type: String  
Length Constraints: Minimum length of 1. Maximum length of 32000.  
Required: No
