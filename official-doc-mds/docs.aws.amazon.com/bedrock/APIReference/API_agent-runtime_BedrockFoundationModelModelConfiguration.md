

# BedrockFoundationModelModelConfiguration
<a name="API_agent-runtime_BedrockFoundationModelModelConfiguration"></a>

Model configuration for a Bedrock foundation model.

## Contents
<a name="API_agent-runtime_BedrockFoundationModelModelConfiguration_Contents"></a>

 ** modelArn **   <a name="bedrock-Type-agent-runtime_BedrockFoundationModelModelConfiguration-modelArn"></a>
The ARN of the Bedrock foundation model.  
Type: String  
Length Constraints: Minimum length of 1. Maximum length of 2048.  
Pattern: `(arn:aws(-[^:]+)?:(bedrock|sagemaker):[a-z0-9-]{1,20}:([0-9]{12})?:([a-z-]+/)?)?([a-z0-9.-]{1,63}){0,2}(([:][a-z0-9-]{1,63}){0,2})?(/[a-z0-9]{1,12})?`   
Required: Yes
