

# IngestionJobSortBy

Type: String

Required: Yes

 ** order **   <a name="bedrock-Type-agent_IngestionJobSortBy-order"></a>
The order for sorting the data.  
Type: String  
Valid Values: `ASCENDING | DESCENDING`   
Required: Yes
