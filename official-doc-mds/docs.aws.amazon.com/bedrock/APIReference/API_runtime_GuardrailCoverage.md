

# GuardrailCoverage

 ** textCharacters **   <a name="bedrock-Type-runtime_GuardrailCoverage-textCharacters"></a>

Type: [GuardrailTextCharactersCoverage](API_runtime_GuardrailTextCharactersCoverage.md) object  
Required: No
