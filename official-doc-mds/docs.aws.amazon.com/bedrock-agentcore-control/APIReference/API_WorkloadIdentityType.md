

# WorkloadIdentityType
<a name="API_WorkloadIdentityType"></a>

Contains information about a workload identity.

## Contents
<a name="API_WorkloadIdentityType_Contents"></a>

 ** name **   <a name="bedrockagentcorecontrol-Type-WorkloadIdentityType-name"></a>
The name of the workload identity.  
Type: String  
Length Constraints: Minimum length of 3. Maximum length of 255.  
Pattern: `[A-Za-z0-9_.-]+`   
Required: Yes

 ** workloadIdentityArn **   <a name="bedrockagentcorecontrol-Type-WorkloadIdentityType-workloadIdentityArn"></a>
The Amazon Resource Name (ARN) of the workload identity.  
Type: String  
Length Constraints: Minimum length of 1. Maximum length of 1024.  
Required: Yes
