

# EpisodicOverrideConfigurationInput
<a name="API_EpisodicOverrideConfigurationInput"></a>

Input for the configuration to override the episodic memory strategy.

## Contents
<a name="API_EpisodicOverrideConfigurationInput_Contents"></a>

 ** consolidation **   <a name="bedrockagentcorecontrol-Type-EpisodicOverrideConfigurationInput-consolidation"></a>
Contains configurations for overriding the consolidation step of the episodic memory strategy.  
Type: [EpisodicOverrideConsolidationConfigurationInput](API_EpisodicOverrideConsolidationConfigurationInput.md) object  
Required: No

 ** extraction **   <a name="bedrockagentcorecontrol-Type-EpisodicOverrideConfigurationInput-extraction"></a>
Contains configurations for overriding the extraction step of the episodic memory strategy.  
Type: [EpisodicOverrideExtractionConfigurationInput](API_EpisodicOverrideExtractionConfigurationInput.md) object  
Required: No

 ** reflection **   <a name="bedrockagentcorecontrol-Type-EpisodicOverrideConfigurationInput-reflection"></a>
Contains configurations for overriding the reflection step of the episodic memory strategy.  
Type: [EpisodicOverrideReflectionConfigurationInput](API_EpisodicOverrideReflectionConfigurationInput.md) object  
Required: No
