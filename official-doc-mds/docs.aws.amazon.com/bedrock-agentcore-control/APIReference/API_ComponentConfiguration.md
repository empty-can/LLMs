

# ComponentConfiguration
<a name="API_ComponentConfiguration"></a>

The configuration for a component within a configuration bundle. The component type is inferred from the component identifier ARN.

## Contents
<a name="API_ComponentConfiguration_Contents"></a>

 ** configuration **   <a name="bedrockagentcorecontrol-Type-ComponentConfiguration-configuration"></a>
The configuration values as a flexible JSON document.  
Type: JSON value  
Required: Yes
