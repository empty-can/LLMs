

# AgentCardDefinition
<a name="API_AgentCardDefinition"></a>

The agent card definition for an A2A descriptor. Contains the schema version and inline content for the agent card.

## Contents
<a name="API_AgentCardDefinition_Contents"></a>

 ** inlineContent **   <a name="bedrockagentcorecontrol-Type-AgentCardDefinition-inlineContent"></a>
The JSON content containing the A2A agent card definition, conforming to the A2A protocol specification.  
Type: String  
Length Constraints: Minimum length of 1. Maximum length of 102400.  
Required: No

 ** schemaVersion **   <a name="bedrockagentcorecontrol-Type-AgentCardDefinition-schemaVersion"></a>
The schema version of the agent card based on the A2A protocol specification.  
Type: String  
Length Constraints: Minimum length of 1. Maximum length of 255.  
Required: No
