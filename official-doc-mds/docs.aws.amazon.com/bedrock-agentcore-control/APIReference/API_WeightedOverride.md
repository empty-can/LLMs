

# WeightedOverride
<a name="API_WeightedOverride"></a>

A weighted configuration bundle override that splits traffic between multiple bundle versions.

## Contents
<a name="API_WeightedOverride_Contents"></a>

 ** trafficSplit **   <a name="bedrockagentcorecontrol-Type-WeightedOverride-trafficSplit"></a>
The traffic split entries defining how traffic is distributed between configuration bundle versions.  
Type: Array of [TrafficSplitEntry](API_TrafficSplitEntry.md) objects  
Array Members: Fixed number of 2 items.  
Required: Yes
