

# MatchPrincipals
<a name="API_MatchPrincipals"></a>

A condition that matches requests based on the caller's identity.

## Contents
<a name="API_MatchPrincipals_Contents"></a>

 ** anyOf **   <a name="bedrockagentcorecontrol-Type-MatchPrincipals-anyOf"></a>
A list of principal entries. The condition is met if any of the entries match the caller's identity.  
Type: Array of [MatchPrincipalEntry](API_MatchPrincipalEntry.md) objects  
Array Members: Minimum number of 1 item. Maximum number of 100 items.  
Required: Yes
