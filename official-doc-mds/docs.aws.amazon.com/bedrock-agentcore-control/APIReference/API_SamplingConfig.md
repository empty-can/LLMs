

# SamplingConfig
<a name="API_SamplingConfig"></a>

 The configuration that controls what percentage of agent traces are sampled for evaluation to manage evaluation volume and costs. 

## Contents
<a name="API_SamplingConfig_Contents"></a>

 ** samplingPercentage **   <a name="bedrockagentcorecontrol-Type-SamplingConfig-samplingPercentage"></a>
 The percentage of agent traces to sample for evaluation, ranging from 0.01% to 100%.   
Type: Double  
Valid Range: Minimum value of 0.01. Maximum value of 100.0.  
Required: Yes
