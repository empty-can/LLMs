

# RuntimeMetadataConfiguration
<a name="API_RuntimeMetadataConfiguration"></a>

Configuration for microVM metadata service settings.

## Contents
<a name="API_RuntimeMetadataConfiguration_Contents"></a>

 ** requireMMDSV2 **   <a name="bedrockagentcorecontrol-Type-RuntimeMetadataConfiguration-requireMMDSV2"></a>
Enables MMDSv2 (microVM Metadata Service Version 2) requirement for the agent runtime. When set to `true`, the runtime microVM will only accept MMDSv2 requests.  
Type: Boolean  
Required: Yes
