

# CategoricalScaleDefinition
<a name="API_CategoricalScaleDefinition"></a>

 The definition of a categorical rating scale option that provides a named category with its description for evaluation scoring. 

## Contents
<a name="API_CategoricalScaleDefinition_Contents"></a>

 ** definition **   <a name="bedrockagentcorecontrol-Type-CategoricalScaleDefinition-definition"></a>
 The description that explains what this categorical rating represents and when it should be used.   
Type: String  
Required: Yes

 ** label **   <a name="bedrockagentcorecontrol-Type-CategoricalScaleDefinition-label"></a>
 The label or name of this categorical rating option.   
Type: String  
Length Constraints: Minimum length of 1. Maximum length of 100.  
Required: Yes
