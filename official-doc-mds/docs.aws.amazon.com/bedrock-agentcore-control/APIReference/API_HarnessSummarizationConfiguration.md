

# HarnessSummarizationConfiguration
<a name="API_HarnessSummarizationConfiguration"></a>

Configuration for summarization-based truncation strategy.

## Contents
<a name="API_HarnessSummarizationConfiguration_Contents"></a>

 ** preserveRecentMessages **   <a name="bedrockagentcorecontrol-Type-HarnessSummarizationConfiguration-preserveRecentMessages"></a>
The number of recent messages to preserve without summarization.  
Type: Integer  
Required: No

 ** summarizationSystemPrompt **   <a name="bedrockagentcorecontrol-Type-HarnessSummarizationConfiguration-summarizationSystemPrompt"></a>
The system prompt used for generating summaries.  
Type: String  
Required: No

 ** summaryRatio **   <a name="bedrockagentcorecontrol-Type-HarnessSummarizationConfiguration-summaryRatio"></a>
The ratio of content to summarize.  
Type: Float  
Required: No
