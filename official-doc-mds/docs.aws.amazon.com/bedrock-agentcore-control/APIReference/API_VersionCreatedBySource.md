

# VersionCreatedBySource
<a name="API_VersionCreatedBySource"></a>

The source that created a configuration bundle version.

## Contents
<a name="API_VersionCreatedBySource_Contents"></a>

 ** name **   <a name="bedrockagentcorecontrol-Type-VersionCreatedBySource-name"></a>
The name of the source (for example, `user`, `optimization-job`, or `system`).  
Type: String  
Required: Yes

 ** arn **   <a name="bedrockagentcorecontrol-Type-VersionCreatedBySource-arn"></a>
The Amazon Resource Name (ARN) of the source, if applicable (for example, a user ARN or optimization job ARN).  
Type: String  
Required: No
