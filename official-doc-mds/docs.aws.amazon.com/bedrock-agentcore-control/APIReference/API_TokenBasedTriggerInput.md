

# TokenBasedTriggerInput
<a name="API_TokenBasedTriggerInput"></a>

Trigger configuration based on tokens.

## Contents
<a name="API_TokenBasedTriggerInput_Contents"></a>

 ** tokenCount **   <a name="bedrockagentcorecontrol-Type-TokenBasedTriggerInput-tokenCount"></a>
Number of tokens that trigger memory processing.  
Type: Integer  
Valid Range: Minimum value of 100. Maximum value of 500000.  
Required: No
