

# SystemManagedBlock
<a name="API_SystemManagedBlock"></a>

System-managed metadata for rules created by automated processes such as A/B tests.

## Contents
<a name="API_SystemManagedBlock_Contents"></a>

 ** managedBy **   <a name="bedrockagentcorecontrol-Type-SystemManagedBlock-managedBy"></a>
The identifier of the system or process that manages this rule.  
Type: String  
Required: Yes
