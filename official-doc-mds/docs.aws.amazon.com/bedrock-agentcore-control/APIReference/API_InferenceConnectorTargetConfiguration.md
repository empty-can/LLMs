

# InferenceConnectorTargetConfiguration
<a name="API_InferenceConnectorTargetConfiguration"></a>

The configuration for a connector-based inference target. This configuration uses a built-in connector that provides predefined rules for a large language model (LLM) provider.

## Contents
<a name="API_InferenceConnectorTargetConfiguration_Contents"></a>

 ** source **   <a name="bedrockagentcorecontrol-Type-InferenceConnectorTargetConfiguration-source"></a>
The source configuration identifying which inference connector to use.  
Type: [InferenceConnectorSource](API_InferenceConnectorSource.md) object  
Required: Yes
