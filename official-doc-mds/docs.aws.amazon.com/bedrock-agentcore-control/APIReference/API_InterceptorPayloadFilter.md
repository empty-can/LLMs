

# InterceptorPayloadFilter
<a name="API_InterceptorPayloadFilter"></a>

The filter that controls which fields of the request or response payload are included in the input to the interceptor.

## Contents
<a name="API_InterceptorPayloadFilter_Contents"></a>

 ** exclude **   <a name="bedrockagentcorecontrol-Type-InterceptorPayloadFilter-exclude"></a>
The list of selectors that identify payload fields to exclude from the interceptor input.  
Type: Array of [InterceptorPayloadExclusionSelector](API_InterceptorPayloadExclusionSelector.md) objects  
Array Members: Fixed number of 1 item.  
Required: Yes
