

# SemanticMemoryStrategyInput
<a name="API_SemanticMemoryStrategyInput"></a>

Input for creating a semantic memory strategy.

## Contents
<a name="API_SemanticMemoryStrategyInput_Contents"></a>

 ** name **   <a name="bedrockagentcorecontrol-Type-SemanticMemoryStrategyInput-name"></a>
The name of the semantic memory strategy.  
Type: String  
Pattern: `[a-zA-Z][a-zA-Z0-9_]{0,47}`   
Required: Yes

 ** description **   <a name="bedrockagentcorecontrol-Type-SemanticMemoryStrategyInput-description"></a>
The description of the semantic memory strategy.  
Type: String  
Length Constraints: Minimum length of 1. Maximum length of 4096.  
Required: No

 ** memoryRecordSchema **   <a name="bedrockagentcorecontrol-Type-SemanticMemoryStrategyInput-memoryRecordSchema"></a>
Schema for metadata on memory records generated by a strategy.  
Type: [MemoryRecordSchema](API_MemoryRecordSchema.md) object  
Required: No

 ** namespaces **   <a name="bedrockagentcorecontrol-Type-SemanticMemoryStrategyInput-namespaces"></a>
 *This member has been deprecated.*   
This is a legacy parameter, use `namespaceTemplates`. The namespaces associated with the semantic memory strategy.  
Type: Array of strings  
Array Members: Fixed number of 1 item.  
Length Constraints: Minimum length of 1. Maximum length of 512.  
Pattern: `[a-zA-Z0-9\-_\/]*(\{(actorId|sessionId|memoryStrategyId)\}[a-zA-Z0-9\-_\/]*)*`   
Required: No

 ** namespaceTemplates **   <a name="bedrockagentcorecontrol-Type-SemanticMemoryStrategyInput-namespaceTemplates"></a>
The namespaceTemplates associated with the semantic memory strategy.  
Type: Array of strings  
Array Members: Fixed number of 1 item.  
Length Constraints: Minimum length of 1. Maximum length of 512.  
Pattern: `[a-zA-Z0-9\-_\/]*(\{(actorId|sessionId|memoryStrategyId)\}[a-zA-Z0-9\-_\/]*)*`   
Required: No
