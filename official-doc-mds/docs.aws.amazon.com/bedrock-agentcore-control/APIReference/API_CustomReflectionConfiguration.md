

# CustomReflectionConfiguration
<a name="API_CustomReflectionConfiguration"></a>

Contains configurations for a custom reflection strategy.

## Contents
<a name="API_CustomReflectionConfiguration_Contents"></a>

**Important**  
This data type is a UNION, so only one of the following members can be specified when used or returned.

 ** episodicReflectionOverride **   <a name="bedrockagentcorecontrol-Type-CustomReflectionConfiguration-episodicReflectionOverride"></a>
The configuration for a reflection strategy to override the default one.  
Type: [EpisodicReflectionOverride](API_EpisodicReflectionOverride.md) object  
Required: No
