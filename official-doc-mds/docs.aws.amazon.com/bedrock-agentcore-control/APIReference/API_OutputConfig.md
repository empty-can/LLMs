

# OutputConfig
<a name="API_OutputConfig"></a>

 The configuration that specifies where evaluation results should be written for monitoring and analysis. 

## Contents
<a name="API_OutputConfig_Contents"></a>

 ** cloudWatchConfig **   <a name="bedrockagentcorecontrol-Type-OutputConfig-cloudWatchConfig"></a>
 The CloudWatch configuration for writing evaluation results to CloudWatch logs with embedded metric format.   
Type: [CloudWatchOutputConfig](API_CloudWatchOutputConfig.md) object  
Required: Yes
