

# SummaryMemoryStrategyInput
<a name="API_SummaryMemoryStrategyInput"></a>

Input for creating a summary memory strategy.

## Contents
<a name="API_SummaryMemoryStrategyInput_Contents"></a>

 ** name **   <a name="bedrockagentcorecontrol-Type-SummaryMemoryStrategyInput-name"></a>
The name of the summary memory strategy.  
Type: String  
Pattern: `[a-zA-Z][a-zA-Z0-9_]{0,47}`   
Required: Yes

 ** description **   <a name="bedrockagentcorecontrol-Type-SummaryMemoryStrategyInput-description"></a>
The description of the summary memory strategy.  
Type: String  
Length Constraints: Minimum length of 1. Maximum length of 4096.  
Required: No

 ** memoryRecordSchema **   <a name="bedrockagentcorecontrol-Type-SummaryMemoryStrategyInput-memoryRecordSchema"></a>
Schema for metadata fields on records generated by this strategy.  
Type: [MemoryRecordSchema](API_MemoryRecordSchema.md) object  
Required: No

 ** namespaces **   <a name="bedrockagentcorecontrol-Type-SummaryMemoryStrategyInput-namespaces"></a>
 *This member has been deprecated.*   
This is a legacy parameter, use `namespaceTemplates`. The namespaces associated with the summary memory strategy.  
Type: Array of strings  
Array Members: Fixed number of 1 item.  
Length Constraints: Minimum length of 1. Maximum length of 512.  
Pattern: `[a-zA-Z0-9\-_\/]*(\{(actorId|sessionId|memoryStrategyId)\}[a-zA-Z0-9\-_\/]*)*`   
Required: No

 ** namespaceTemplates **   <a name="bedrockagentcorecontrol-Type-SummaryMemoryStrategyInput-namespaceTemplates"></a>
The namespaceTemplates associated with the summary memory strategy.  
Type: Array of strings  
Array Members: Fixed number of 1 item.  
Length Constraints: Minimum length of 1. Maximum length of 512.  
Pattern: `[a-zA-Z0-9\-_\/]*(\{(actorId|sessionId|memoryStrategyId)\}[a-zA-Z0-9\-_\/]*)*`   
Required: No
