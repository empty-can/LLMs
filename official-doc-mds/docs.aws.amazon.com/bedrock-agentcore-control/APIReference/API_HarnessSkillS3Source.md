

# HarnessSkillS3Source
<a name="API_HarnessSkillS3Source"></a>

An S3 source for a skill.

## Contents
<a name="API_HarnessSkillS3Source_Contents"></a>

 ** uri **   <a name="bedrockagentcorecontrol-Type-HarnessSkillS3Source-uri"></a>
The S3 URI pointing to the skill directory (e.g., s3://bucket/skills/my-skill/).  
Type: String  
Length Constraints: Minimum length of 5.  
Pattern: `s3://.*`   
Required: Yes
