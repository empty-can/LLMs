

# MessageBasedTriggerInput
<a name="API_MessageBasedTriggerInput"></a>

The trigger configuration based on a message.

## Contents
<a name="API_MessageBasedTriggerInput_Contents"></a>

 ** messageCount **   <a name="bedrockagentcorecontrol-Type-MessageBasedTriggerInput-messageCount"></a>
The number of messages that trigger memory processing.  
Type: Integer  
Valid Range: Minimum value of 1. Maximum value of 50.  
Required: No
