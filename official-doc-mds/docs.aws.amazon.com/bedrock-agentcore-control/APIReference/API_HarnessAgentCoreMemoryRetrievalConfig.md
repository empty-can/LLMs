

# HarnessAgentCoreMemoryRetrievalConfig
<a name="API_HarnessAgentCoreMemoryRetrievalConfig"></a>

Configuration for memory retrieval within a namespace.

## Contents
<a name="API_HarnessAgentCoreMemoryRetrievalConfig_Contents"></a>

 ** relevanceScore **   <a name="bedrockagentcorecontrol-Type-HarnessAgentCoreMemoryRetrievalConfig-relevanceScore"></a>
The minimum relevance score for retrieved memories.  
Type: Float  
Required: No

 ** strategyId **   <a name="bedrockagentcorecontrol-Type-HarnessAgentCoreMemoryRetrievalConfig-strategyId"></a>
The ID of the retrieval strategy to use.  
Type: String  
Required: No

 ** topK **   <a name="bedrockagentcorecontrol-Type-HarnessAgentCoreMemoryRetrievalConfig-topK"></a>
The maximum number of memory entries to retrieve.  
Type: Integer  
Required: No
