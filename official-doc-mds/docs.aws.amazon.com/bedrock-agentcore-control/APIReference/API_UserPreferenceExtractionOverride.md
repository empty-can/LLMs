

# UserPreferenceExtractionOverride
<a name="API_UserPreferenceExtractionOverride"></a>

Contains user preference extraction override configuration.

## Contents
<a name="API_UserPreferenceExtractionOverride_Contents"></a>

 ** appendToPrompt **   <a name="bedrockagentcorecontrol-Type-UserPreferenceExtractionOverride-appendToPrompt"></a>
The text to append to the prompt for user preference extraction.  
Type: String  
Length Constraints: Minimum length of 1. Maximum length of 30000.  
Required: Yes

 ** modelId **   <a name="bedrockagentcorecontrol-Type-UserPreferenceExtractionOverride-modelId"></a>
The model ID to use for user preference extraction.  
Type: String  
Required: Yes
