

# SkillMdDefinition
<a name="API_SkillMdDefinition"></a>

The skill markdown definition for an agent skills descriptor.

## Contents
<a name="API_SkillMdDefinition_Contents"></a>

 ** inlineContent **   <a name="bedrockagentcorecontrol-Type-SkillMdDefinition-inlineContent"></a>

Type: String  
Length Constraints: Minimum length of 1. Maximum length of 102400.  
Required: No
