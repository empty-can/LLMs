

# MemoryRecordSchema
<a name="API_MemoryRecordSchema"></a>

Schema for metadata on memory records generated by a strategy.

## Contents
<a name="API_MemoryRecordSchema_Contents"></a>

 ** metadataSchema **   <a name="bedrockagentcorecontrol-Type-MemoryRecordSchema-metadataSchema"></a>
The metadata field definitions for this strategy.  
Type: Array of [MetadataSchemaEntry](API_MetadataSchemaEntry.md) objects  
Array Members: Minimum number of 1 item. Maximum number of 20 items.  
Required: No
