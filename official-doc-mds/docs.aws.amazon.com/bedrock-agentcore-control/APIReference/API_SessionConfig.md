

# SessionConfig
<a name="API_SessionConfig"></a>

 The configuration that defines how agent sessions are detected and when they are considered complete for evaluation. 

## Contents
<a name="API_SessionConfig_Contents"></a>

 ** sessionTimeoutMinutes **   <a name="bedrockagentcorecontrol-Type-SessionConfig-sessionTimeoutMinutes"></a>
 The number of minutes of inactivity after which an agent session is considered complete and ready for evaluation. Default is 15 minutes.   
Type: Integer  
Valid Range: Minimum value of 1. Maximum value of 1440.  
Required: Yes
