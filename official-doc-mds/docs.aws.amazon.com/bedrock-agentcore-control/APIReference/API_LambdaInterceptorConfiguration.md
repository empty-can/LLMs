

# LambdaInterceptorConfiguration
<a name="API_LambdaInterceptorConfiguration"></a>

The lambda configuration for the interceptor

## Contents
<a name="API_LambdaInterceptorConfiguration_Contents"></a>

 ** arn **   <a name="bedrockagentcorecontrol-Type-LambdaInterceptorConfiguration-arn"></a>
The arn of the lambda function to be invoked for the interceptor.  
Type: String  
Length Constraints: Minimum length of 1. Maximum length of 170.  
Pattern: `arn:(aws[a-zA-Z-]*)?:lambda:([a-z]{2}(-gov)?-[a-z]+-\d{1}):(\d{12}):function:([a-zA-Z0-9-_.]+)(:(\$LATEST|[a-zA-Z0-9-_]+))?`   
Required: Yes
