## 1. Tasks 拡張仕様リポジトリの改称と見出し正規化

MCP 公式ドキュメントの Tasks 拡張（長時間実行 MCP 操作のための非同期タスク実行）概要ページで、完全仕様とドキュメントを収録する GitHub リポジトリの参照先が `modelcontextprotocol/experimental-ext-tasks` から `modelcontextprotocol/ext-tasks` へ改称されました。概要ページ上部の Card コンポーネントのタイトルとリンク先 URL がこの新リポジトリ名に更新されています。リポジトリ名から `experimental-` の接頭辞が外れたことは、Tasks 拡張のホスト先が実験段階の位置づけから整理されつつあることを示唆します。

あわせて、ページ本文の見出しが「MCP Tasks」から「Tasks」へ変更されました。これは前回の対象期間に拡張機能インデックス（`llms.txt`）の索引タイトルで行われた「MCP」接頭辞なしへの正規化に、ページ本文側の見出しが追従したものです。リンク先 URL（`/extensions/tasks/overview`）・説明文・タスクの解説本文そのものに変更はありません。

- [タスク拡張（Tasks） - MCP Docs](https://modelcontextprotocol.io/extensions/tasks/overview)
