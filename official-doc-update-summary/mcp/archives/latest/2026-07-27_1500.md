# MCP 公式ドキュメント更新サマリ

```markdown
今回の対象期間の原文差分は 1 ページ・計 4 か所で、いずれも認可チュートリアル「Understanding Authorization in MCP」の Python 実装例に対する変更です。ハードコードされた資格情報の除去、パブリッククライアントへの対応、トークン検証のバグ修正、パッケージ構成と起動手順の追加の 4 点が入りました。

主要なものを以下に挙げます。

1. `config.py` の例からハードコードされたクライアントシークレットが除かれ、プレースホルダに置き換えられた
2. トークンイントロスペクションが `client_secret` を設定時のみ送るようになり、パブリッククライアントでも使えるようになった
3. Keycloak がリストで返す `aud` を `AccessToken.resource` にそのまま渡して silent 401 になる問題が修正された
4. Python サーバーの `pyproject.toml` 例と `uv` による起動コマンドを示す節が追加された
```

## ハイライト

1. [**Python 例からハードコードされたクライアントシークレットを除去**](../latest-detail/2026-07-27_1500.md#1-python-例からハードコードされたクライアントシークレットを除去):  
  `config.py` の `OAUTH_CLIENT_SECRET` の既定値が実値らしき文字列からプレースホルダ `<YOUR_SERVER_CLIENT_SECRET>` に置き換えられ、あわせて `OAUTH_CLIENT_ID` の既定値も `mcp-server` から `test-client` に変更された。
2. [**トークンイントロスペクションがパブリッククライアントに対応**](../latest-detail/2026-07-27_1500.md#2-トークンイントロスペクションがパブリッククライアントに対応):  
  イントロスペクション要求のフォームデータに `client_secret` を常に載せるのをやめ、設定されている場合のみ付与するようになった。シークレットを持たないパブリッククライアントは `client_id` だけで認証する。
3. [**リスト形式の aud による silent 401 を修正**](../latest-detail/2026-07-27_1500.md#3-リスト形式の-aud-による-silent-401-を修正):  
  `AccessToken.resource` に `aud` クレームをそのまま渡していた箇所が `self.resource_url` に変更された。Keycloak が `aud` をリストで返すと pydantic の `ValidationError` が広い `except` に飲み込まれ、理由の見えない 401 になっていた。
4. [**Python サーバーのパッケージ構成と起動手順を追加**](../latest-detail/2026-07-27_1500.md#4-python-サーバーのパッケージ構成と起動手順を追加):  
  Python タブの末尾に `pyproject.toml` の記述例と `uv sync` / `uv run` による起動コマンドを示す節が追加され、コード例だけでは分からなかったファイル配置と実行方法が補われた。
