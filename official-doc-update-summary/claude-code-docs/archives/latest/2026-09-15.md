**新機能**

- **サブエージェント frontmatter と `--agents` JSON に `omitClaudeMd` が加わりました**。ユーザー・プロジェクト・ローカルの CLAUDE.md を読まずにサブエージェントを起動できます（詳細はハイライト 2 参照）— [Create custom subagents](https://code.claude.com/docs/en/sub-agents#supported-frontmatter-fields)
- **`claude plugin install` / `update` に `--accept-command <sha256>` が加わりました**。`-y` の代わりに、直前の `--json` 実行が表示した 1 つのコマンドだけを受理します（詳細は大幅更新 1 参照）— [Plugins reference](https://code.claude.com/docs/en/plugins-reference#plugin-install)
- **クラウドセッション（Anthropic 管理・セルフホストランナーのいずれも）で高速モードが使えるようになりました**。`/fast on` で有効になりますが**そのセッション限り**で、既定としては保存されません。`claude-code-on-the-web` 側でも `/fast` が独立した項目に分離され、引数形式の一覧から外れました — [日本語](https://code.claude.com/docs/ja/fast-mode#use-fast-mode-in-cloud-sessions) / [Speed up responses with fast mode](https://code.claude.com/docs/en/fast-mode#use-fast-mode-in-cloud-sessions)
- **動的ワークフローが使用量上限で一時停止するようになりました**。上限に達したエージェントを失敗させず、リセットを待って自動で続行します。**対話型・claude.ai サブスクリプション・`autoContinueAtUsageLimit` 有効・リセットが 24 時間以内・その実行がまだ 2 回しか待っていない、の 4 条件すべてを満たす場合のみ**で、1 つでも欠ければ従来どおり失敗します（詳細はハイライト 3 参照）— [Orchestrate subagents at scale with dynamic workflows](https://code.claude.com/docs/en/workflows#when-a-run-hits-your-usage-limit)
- **Claude apps ゲートウェイと `modelPricing` の `multiplier` 上限が 1 から 10 へ拡大され、1 を超える値を「上乗せ」として設定できるようになりました**。`admin:` ブロックがあると**支出上限にも効く**ためゲートウェイは起動時に警告を出し、**上流プロバイダへの請求額は変わりません**。**v2.1.271 より前のゲートウェイサーバーは 1 超の値を設定すると起動を拒否**し、**v2.1.271 より前のクライアントは 1 超の `multiplier` を無視**します — [Claude apps gateway configuration](https://code.claude.com/docs/en/claude-apps-gateway-config#mark-prices-up) / [日本語](https://code.claude.com/docs/ja/settings-reference#modelpricing) / [All settings](https://code.claude.com/docs/en/settings-reference#modelpricing)
- **セルフホストランナーに `--drain-marker-file <path>` が加わりました**。`SIGTERM` によるドレイン開始時にそのファイルが存在すると、**ランナーは終了をホスト由来のドレインとして Anthropic に報告**します（テレメトリのみで、ドレインの挙動自体は変わりません）。**セッションから書き込めないローカルファイルシステム上のパスを指定する**よう指示されています — [日本語](https://code.claude.com/docs/ja/self-hosted-environments-reference#runner-cli-flags) / [Self-hosted environments reference](https://code.claude.com/docs/en/self-hosted-environments-reference#runner-cli-flags)
- **同じくランナーに `--host-config-snapshot disk|memory` が加わりました**（既定 `disk`）。`disk` は `--base-dir` 配下へスナップショットを複製し、**セッション開始のたびに全ファイルをメモリ上のダイジェストと照合**、改変を検出するとセッションを失敗させ再起動まで新規セッションを拒否します。`memory` は**64 MiB 上限でヒープに保持**し、超えるとホスト設定なしで起動して通知を出します — [日本語](https://code.claude.com/docs/ja/self-hosted-environments-reference#runner-cli-flags) / [Self-hosted environments reference](https://code.claude.com/docs/en/self-hosted-environments-reference#runner-cli-flags)
- **`userConfig` に `options` フィールドが加わりました**。`string` 型で受け付ける値を列挙し、`/config` ではピッカーとして表示されます（詳細は大幅更新 1 参照）— [日本語](https://code.claude.com/docs/ja/plugins-reference#user-configuration) / [Plugins reference](https://code.claude.com/docs/en/plugins-reference#user-configuration)

- **VS Code 拡張のプロンプトボックスにプロンプトキャッシュの時計が加わりました**。会話の[日本語](https://code.claude.com/docs/ja/prompt-caching) / [プロンプトキャッシュ](https://code.claude.com/docs/en/prompt-caching)の残り時間を推定して `12m` のように表示し、**切れると分表示が消えてアイコンがエラー色になります**。**圧縮直後も同じく赤くなります**（圧縮後の会話をキャッシュがまだ覆っていないため）。**モデルを切り替えても時計はリセットされない**ので、切り替え後も分が残って見えることがあります — [Use Claude Code in VS Code](https://code.claude.com/docs/en/vs-code#use-the-prompt-box)

- **`/diff` パネルの行選択を送信前に取り消せるようになりました**。**行数インジケータの直後にカーソルを置いて `Backspace`** を押すと、選択を添付せずにプロンプトを送れます — [日本語](https://code.claude.com/docs/ja/interactive-mode#diff-panel) / [Interactive mode](https://code.claude.com/docs/en/interactive-mode#diff-panel)
