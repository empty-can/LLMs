## 軽微な更新

今回の軽微な更新は、ドキュメントの記述更新（見出しの改称・リファレンス項目やトラブルシューティング事例の追加）と、changelog への内部改善エントリ（v2.1.159）の追記です。

**機能改善**
- インタラクティブモードのリファレンスに、プラグインの有効化・無効化操作の項目が追加されました。 — [日本語](https://code.claude.com/docs/ja/interactive-mode#commands) / [English](https://code.claude.com/docs/en/interactive-mode#commands)
- トラブルシューティングページに、バックグラウンドサービスが応答しないケースと、macOS でバックグラウンドセッションがデスクトップ・書類・ダウンロードフォルダを読めないケースの 2 項目が追加されました。 — [日本語](https://code.claude.com/docs/ja/troubleshooting) / [English](https://code.claude.com/docs/en/troubleshooting)

**その他**
- フックのガイドページのタイトルが「Automate workflows with hooks」から「Automate actions with hooks」へ変更されました（内容は同一で表現の調整）。 — [日本語](https://code.claude.com/docs/ja/hooks-guide) / [English](https://code.claude.com/docs/en/hooks-guide)
- `/goal` ページの見出しが「Compare to other autonomous workflows」から「Compare ways to keep a session running」へ改称されました。 — [日本語](https://code.claude.com/docs/ja/goal#compare-ways-to-keep-a-session-running) / [English](https://code.claude.com/docs/en/goal#compare-ways-to-keep-a-session-running)
- changelog に v2.1.159（2026年05月31日）が追記されました。内部インフラの改善のみで、ユーザー向けの変更はありません。
