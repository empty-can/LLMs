## ハイライト

1. [**Code タブで効き方が変わる Claude Code の設定キーの表が desktop に載った**](../latest-detail/2026-11-01.md#1-code-タブで効き方が変わる-claude-code-の設定キーの表が-desktop-に載った):  
  `desktop` の「Enterprise configuration」の「Managed settings」の下に h4「Claude Code settings that behave differently in the Code tab」ができ、ローカルのセッションでは Code タブがターミナルの画面の代わりになるため効き方が変わるか目に見える効果がないキーが、15 行の表（18 のキー）で載りました。ターミナルでは引き続き効くので、設定したままでよいとされています
2. [**Claude Desktop の SSH セッションの記述が 4 か所補われた**](../latest-detail/2026-11-01.md#2-claude-desktop-の-ssh-セッションの記述が-4-か所補われた):  
  SSH セッションでは Claude に Browser ペインのツールがないため、アプリをペインで開くことも変更の自動の検証もできず、**Dev servers** のメニューと設定したプレビューのサーバーも使えない、と載りました。プロキシに加えて CA 証明書が要るときの案内とエラーの文、ヘルパーの前回の実行のログ `remote-server.log.old` も加わっています
3. [**setup の追加の依存関係に Git の版の条件が集められた**](../latest-detail/2026-11-01.md#3-setup-の追加の依存関係に-git-の版の条件が集められた):  
  「Additional dependencies」に Git の項目が加わり、Git は任意で、git があれば `claude plugin eval` には 2.31 以降が、macOS・Linux・WSL からクラウドのセッションへローカルのリポジトリをアップロードするには git 2.31 以降が要る、と載りました。どちらも前から各ページにあった条件です

今回の差分は **2 ファイル**（`llms-full.txt`・見出しマップ）で、`llms.txt` は変わっていません。前回の取り込みの次の取り込み（`40e2702`）では mcp のファイルだけが変わり、Claude Code のファイルに差分がなかったため、今回の対象期間は 2 回分の取り込みにまたがっています。`llms-full.txt` は 228 ページ中 2 ページ（`desktop`・`setup`）に差分があり、どちらもハイライトで取り上げています。changelog に新しいリリースはなく、収録リリースは 434 のまま（最新は前回と同じ v2.1.316）です。
