## 1. ストリームストール時のヒント表示の変更

API からの応答ストリームが一時的に停止した（ストリームストール）際に表示されるヒントの文言とトリガー間隔が変更されました（v2.1.185、2026年06月20日）。文言は従来の「No response from API · Retrying in …」（API から応答なし · …後に再試行）から「Waiting for API response · will retry in …」（API 応答を待機中 · …後に再試行）に改められ、まだ応答を待っている状態であることがより明確に伝わる表現になりました。

あわせて、このヒントが表示されるまでの無音待機時間が 10 秒から 20 秒に延長されました。短時間の応答遅延では従来より早期にヒントが出なくなり、通常の遅延と本当の停止をより区別しやすくなります。本変更は changelog のみで言及されており、対応する通常ドキュメントページはありません。
