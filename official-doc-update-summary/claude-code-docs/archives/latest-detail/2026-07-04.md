## 1. Amazon Bedrock と Microsoft Foundry の正式名称統一

Claude Code ドキュメントの原文全文（llms-full）で、単独表記だった **「Bedrock」が「Amazon Bedrock」へ、「Foundry」が「Microsoft Foundry」へ** 一斉に統一されました。前回の対象期間で「Vertex AI → Google Cloud's Agent Platform」改称が先行しましたが、今回はそれと同じ表記正規化の一環として、残る 2 プロバイダの短縮表記も正式名称へ揃えた形です。波及範囲は広く、機能可用性表（`feature-availability`）、Claude apps ゲートウェイの設定・デプロイ・スペンドリミット、認証・データ利用・エラーリファレンス、`third-party-integrations`、GitHub Actions／GitLab CI/CD の設定例など、プロバイダ名に言及するほぼ全ページに及びます。

一方で **これは名称のみの変更** です。環境変数（`CLAUDE_CODE_USE_BEDROCK`・`CLAUDE_CODE_USE_FOUNDRY`・`CLAUDE_CODE_USE_MANTLE` 等）、URL パス（`/amazon-bedrock`・`/microsoft-foundry`）、および見出しに紐づくセクションアンカーは据え置きで、`## Sign in with Bedrock`（`amazon-bedrock` ページ）などの見出しテキストも「Amazon Bedrock」化されていません。したがって Bedrock／Foundry 側では内部アンカーの変更は発生していません（アンカーが変わったのは Agent Platform 側のみ。ハイライト 2 参照）。なお日本語版ページ群は本サマリ作成時点で表記が混在（「Amazon Bedrock」と「Bedrock」など）しており、この en 側の正規化を一律には反映していないため、日本語リンクは省略しています。

- [Feature availability (Availability by model provider) - Claude Code Docs (English)](https://code.claude.com/docs/en/feature-availability#availability-by-model-provider)
- [日本語](https://code.claude.com/docs/ja/amazon-bedrock) / [Claude Code on Amazon Bedrock - Claude Code Docs (English)](https://code.claude.com/docs/en/amazon-bedrock)

> 本節は en 原文全文の表記正規化のみで、機能・環境変数・アンカーは不変です。日本語版はプロバイダ名の表記が独立・混在しており（2026-07-05 時点で ja `feature-availability` を WebFetch で確認。「Amazon Bedrock」と「Bedrock」等が混在）、この en 側の正規化を一律には反映していないため日本語リンクは省略しています。

## 2. Google Cloud's Agent Platform リブランドの全文波及とアンカー改称

前回の対象期間で `llms.txt` のページタイトル・説明とドキュメントマップに先行反映されていた **「Google Vertex AI／Vertex AI → Google Cloud's Agent Platform」** 改称が、今回、原文全文（llms-full）の本文と多数のセクション見出しへ波及しました。プロバイダを列挙する多数の文（認証・データ利用・機能可用性・ゲートウェイ・エラー・CI 例など）で「Vertex」「Vertex AI」「Google Vertex AI」「Google Cloud Vertex AI」が「Google Cloud's Agent Platform」へ置き換わっています。

**今回の diff では見出し自体が改称され、それに伴ってアンカーも変化しています**。Vertex を含む多数の見出しが対象で、例として `## Sign in with Vertex AI`→`## Sign in with Agent Platform`（`#sign-in-with-vertex-ai`→`#sign-in-with-agent-platform`）、`### Enable auto mode on Bedrock, Vertex AI, or Foundry`→`### Enable auto mode on Bedrock, Agent Platform, or Foundry`（`#enable-auto-mode-on-bedrock-vertex-ai-or-foundry`→`#enable-auto-mode-on-bedrock-agent-platform-or-foundry`）のほか、`### 1. Enable Vertex AI API`→`### 1. Enable Agent Platform API`、`#### Enable fallback on Bedrock, Vertex AI, and Foundry`→`#### Enable fallback on Bedrock, Agent Platform, and Foundry`、`### Bedrock, Vertex, or Foundry credentials not loading`→`### Bedrock, Agent Platform, or Foundry credentials not loading` などが同時に改称されました。これらの見出しを指す `feature-availability`・`desktop`・`claude-apps-gateway-config` などからの内部参照リンクも同一 diff 内でアンカーへ追従しています。**旧アンカーを指す外部からの deep link は切れる**ため、これらの節へブックマーク等でリンクしていた場合は張り替えが必要です。なお見出し中でも「Bedrock」「Foundry」は短縮表記のまま維持され（例: `Enable auto mode on Bedrock, Agent Platform, or Foundry`）、正式名称化されたのは本文散文のみです（ハイライト1参照）。あわせて、GitHub Actions・GitLab CI/CD 両ページの節見出しも「Using with Amazon Bedrock & Google Vertex AI」→「Using with Amazon Bedrock and Google Cloud」に変わり、そのアンカーが `#using-with-amazon-bedrock-and-google-cloud` へ変化しました（軽微な更新に記載）。日本語版 `permission-modes`・`google-vertex-ai` ページは本サマリ作成時点で「Vertex AI」表記のままで、ja の auto-mode 見出しアンカーも旧 `enable-auto-mode-on-bedrock-vertex-ai-or-foundry` のため、日本語リンクは省略しています。

- [Claude Code on Google Cloud's Agent Platform (Sign in with Agent Platform) - Claude Code Docs (English)](https://code.claude.com/docs/en/google-vertex-ai#sign-in-with-agent-platform)
- [Choose a permission mode (Enable auto mode on Bedrock, Agent Platform, or Foundry) - Claude Code Docs (English)](https://code.claude.com/docs/en/permission-modes#enable-auto-mode-on-bedrock-agent-platform-or-foundry)

> 本節のリブランドは en 側で反映済みですが、日本語版は本サマリ作成時点で「Vertex AI」表記・旧アンカーのままのため、日本語リンクは省略しています（2026-07-05 時点で ja `permission-modes` を WebFetch で確認。auto-mode 節の見出しは「Bedrock、Vertex AI、または Foundry で自動モードを有効にする」、アンカーも旧 `enable-auto-mode-on-bedrock-vertex-ai-or-foundry` のまま）。
