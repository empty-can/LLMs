### 追加（13 件）の主なもの

- **`settings.json` で `"attribution": false` と書くと、コミットと PR の帰属表示をすべて隠せる**ようになりました。ただし**古い CLI はこの値を含む設定ファイルを丸ごと読み飛ばす**ため、複数の版で共有するファイルではオブジェクト形式のままにするよう注記されています
- **Claude apps gateway の Bedrock アップストリーム**に **`assume_role`**（STS 経由で IAM ロールを引き受けて Bedrock を呼ぶ。別 AWS アカウントでもよく、開発者ごとに 1 セッションにもできる）と **`guardrail: {id, version}`**（全リクエストに Amazon Bedrock のガードレールを適用する。全 Bedrock アップストリームに設定するか、どれにも設定しないかのどちらか）が加わりました。あわせて **`telemetry.resource_attributes`**（Claude Desktop と `/login` セッションのテレメトリに固定ラベルを付ける）と、`desktop` ポリシーブロックでの新しいキー（`blockReadsOutsideWorkingDirectories`・`disableBypassPermissionsMode` など）への対応も入りました
- **MCP の URL モード elicitation**（`2026-07-28` プロトコル接続で、サーバーがブラウザでの操作フローを開かせる）
- **`claude plugin validate` の MCP サーバー検査**（読み込み時に黙って捨てられる `.mcp.json` エントリ、宣言していない `${user_config.*}` 参照、安全でない URL を報告する）
- **`/insights` の auto モード推奨**（最近のセッションで auto モードが肩代わりできた権限プロンプトの数を見積もる）

### 変更（17 件）のうち挙動が大きく変わるもの

- **送信の即時実行（`ctrl+enter` / `ctrl+x ctrl+s`）は、ターンを中断せず、実行中のツールをバックグラウンドへ移すようになりました。** 前回サマリは v2.1.275 の新機能として「実行中のターンを中断して、キューのメッセージと下書きを一度に出す」と書きましたが、**その挙動が変わったことになります**。`interactive-mode` の本文は今回動いていないため、**本文はまだ「中断する」という旧記述のまま**です
- **auto モードの分類器レビューをサーバー側で行う環境では、読み取り専用のシェルコマンドやサンドボックス内のコマンドもレビューを待ち、問題ありと判定されればブロックされる**ようになりました。**`CLAUDE_CODE_AUTO_MODE_SERVER` は Anthropic API 直結でも効く**ようになり、`0` でサーバー側分類器をオプトアウト（その場合はローカル分類器の分が使用量に数えられる）、`1` でオプトインします。前回サマリの「Anthropic API 直結では読まれない」という記述は、この版で当てはまらなくなりました
- **`--dangerously-skip-permissions` と auto モードでの危険な `rm` の確認は、2 分待って応答がなければコマンドを拒否し、書き換えのヒントを返す**ようになりました。無人セッションを止めないためで、`CLAUDE_CODE_DISABLE_DANGEROUS_RM_TIMEOUT=1` で無効にできます
- **セルフホストランナーが、システムプロンプトをコマンドライン文字列ではなく非公開ファイルとして Claude Code に渡す**ようになりました。**`--system-prompt` / `--append-system-prompt` を後付けするラッパーや `command` フックは、`--system-prompt-file` / `--append-system-prompt-file` に切り替える必要があります**
- **Artifact ツールが、アーティファクトページで unpkg.com のスクリプトを読み込めるようになりました**

**本サマリは方針として changelog ページの URL を掲載しません。** 上記はいずれも、今回の差分では本文ページに対応する記述が見つからないため、リンクを付けていません。
