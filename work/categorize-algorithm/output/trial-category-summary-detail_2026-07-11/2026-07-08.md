### 🔐 パーミッション・セキュリティ — 7件

- **Authentication › Credential management**: 認証ページに「期限切れが近いログインの更新」節が追加された。`/login` で作成したログインの期限が 5 日以内に迫ると起動時に `Your login expires in 3 days · run /login to renew` と警告するようになった（v2.1.203 以降）。警告は情報提供のみでリクエストをブロックせず、claude.ai / Claude Console ログインが有効な認証情報のときだけ表示される。無人実行のバックグラウンドセッションや Remote Control セッションで特に重要となる。 — [English](https://code.claude.com/docs/en/authentication#credential-management)
- **Configure auto mode › Define trusted infrastructure**: auto mode の信頼スロット説明に、リポジトリ可視性による機密情報の扱いが追記された（v2.1.203 以降）。プライベートリポジトリは機密情報の許容される送信先だが、リポジトリを private にしてもシークレットや個人・受託データがクリアされるわけではなく、作業リポジトリ外から持ち込まれた・参照されたコンテンツは当該リポジトリ自身の成果物として扱われない、と明確化された。 — [English](https://code.claude.com/docs/en/auto-mode-config#define-trusted-infrastructure)
- **Claude Code changelog**: changelog に v2.1.204 と v2.1.205（2026-07-08）が追加された。auto mode にセッション transcript ファイル改ざんをブロックするルールを追加、`--json-schema` の不正時挙動や Windows worktree 削除・クラッシュの修正、`SendMessage` で再開したバックグラウンドエージェントの状態表示修正、`/doctor` のセットアップ点検化（`/checkup` はエイリアス）、`rm -rf` の変数未解決時の確認、MCP サーバ名予約など多数の修正・改善が記載された。 — [English](https://code.claude.com/docs/en/changelog)
- **1ページ・2セクション**: エラーリファレンスに「Safety measures flagged a cybersecurity topic」節と対応する索引行が追加された。モデルのセーフティ機構が会話をサイバーセキュリティ関連と判定した際のメッセージ文言が変わり、リンク先が Cyber Verification Program になった（安全機構自体はサーバ側で v2.1.203 以前から存在し、今回は文言とリンクのみ変更）。Amazon Bedrock・Google Cloud・Microsoft Foundry では代わりに Usage Policy 拒否メッセージが出る、非対話モードでは `/feedback` の一文が省かれる、といった条件も追記された。 — [errors](https://code.claude.com/docs/en/errors#find-your-error) / [errors](https://code.claude.com/docs/en/errors#request-errors)
- **Choose a permission mode › Switch permission modes**: permission mode の切り替え説明に、Manual mode（cycle 中の `default`）ではステータスバーにグレーの `⏸ manual mode on` バッジが表示されるようになったことが追記された（v2.1.203 以降、従来はバッジなし）。 — [English](https://code.claude.com/docs/en/permission-modes#switch-permission-modes)
- **Choose a permission mode › Analyze before you edit with plan mode**: plan mode で既定ブロックされる操作の記述が刷新・拡充された。デフォルトブランチへの push は一律ブロックから、機密・秘匿・改変・リポジトリ外由来・レビュー迂回などを伴う場合のブロックへ変わり、素の push は許容されるようになった。PR・issue 本文へのライブ個人データ混入や、機密なローカルストア（セッション transcript、認証・設定 dotfolder 等）由来コンテンツの commit・push・公開が、出所と送信先の両方を明示しない限り既定ブロックされるようになった（v2.1.203 以降）。 — [English](https://code.claude.com/docs/en/permission-modes#analyze-before-you-edit-with-plan-mode)
- **Catch security issues as Claude writes code › Disable or uninstall**: security-guidance プラグインの無効化・アンインストール説明が更新された。プロジェクト設定で有効化されたプラグインを `/plugin` から無効化すると `.claude/settings.local.json` に override が書かれ自分だけ無効化されるが、同じダイアログから共有 `.claude/settings.json` を編集して全員向けにアンインストールする選択肢も提供されるようになった（v2.1.203 以降）。 — [English](https://code.claude.com/docs/en/security-guidance#disable-or-uninstall)

### 🧩 Agent SDK・サブエージェント — 5件

- **Manage multiple agents with agent view › Monitor sessions with agent view**: agent view で ← を押してセッションをバックグラウンド化する際、サブエージェント実行中は 10 秒制限が適用されず作業を引き継ぐため待機を続けるようになった（`Still backgrounding after the current tool` を表示、再度 ← で待たずにバックグラウンド化）。v2.1.203 より前は 10 秒で待機を打ち切りサブエージェントを最初から再起動していた。また履歴のない新規セッションでも行が作られ、単独行の下に出ていたオンボーディングヒントは表示されなくなった。 — [English](https://code.claude.com/docs/en/agent-view#monitor-sessions-with-agent-view)
- **Create custom subagents › Configure subagents**: `isolation: worktree` のサブエージェントは Bash・PowerShell コマンドを自身の worktree 内で実行し、実行中に worktree ディレクトリが削除される等でメインチェックアウトに解決される場合はエラーで失敗するようになった（v2.1.203 以降、従来はメインチェックアウトで実行され得た）。 — [English](https://code.claude.com/docs/en/sub-agents#configure-subagents)
- **Agent SDK reference - TypeScript › Types**: Agent SDK（TypeScript）の `effortLevel` が `"ultracode"` を受け付けるようになった（`xhigh` effort + ultracode 有効化、v2.1.203 以降）。ただし `Settings` 型はこの値を宣言しないため、TypeScript では等価な `{ ultracode: true }` を渡す。`ultracode` は `applyFlagSettings()` のみが受け付け、設定ファイルの `effortLevel` キーは受け付けない。 — [English](https://code.claude.com/docs/en/agent-sdk/typescript#types)
- **1ページ・2セクション**: Agent SDK（TypeScript）に新しいメッセージ型 `SDKBackgroundTasksChangedMessage` と `SDKConversationResetMessage` が追加された（v2.1.203 以降）。前者はバックグラウンドタスク集合の変化時に全ライブ集合を通知し、受信ごとにキャッシュを置き換える運用が示された。後者は `/clear` や plan mode 退出など、セッションを終えずに会話が置換されたときに発火し、空 transcript のマウントとキャッシュ済みタイトルの破棄を促す。 — [agent-sdk/typescript](https://code.claude.com/docs/en/agent-sdk/typescript#message-types) / [agent-sdk/typescript](https://code.claude.com/docs/en/agent-sdk/typescript#other-types)
- **Agent SDK reference - TypeScript › Tool Input Types**: Agent SDK（TypeScript）の `EnterWorktree` ツール入力の説明が更新され、初回入場時の対象は現在リポジトリの登録済み worktree か、マルチリポワークスペースではその内側にネストしたリポジトリの worktree でもよくなった。worktree セッション内からは `.claude/worktrees/` 配下に限られる。 — [English](https://code.claude.com/docs/en/agent-sdk/typescript#tool-input-types)
