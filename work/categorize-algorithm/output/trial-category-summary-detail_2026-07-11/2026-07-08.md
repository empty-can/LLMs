## カテゴリ別の変更点

### ⌨️ コマンド — 2件

- **--effort に ultracode を追加**: CLI リファレンスの `--effort` フラグに `ultracode` が選択肢として追加された（v2.1.203〜）。`ultracode` はセッションを `xhigh` で開始しつつ ultracode を有効化する。当セッション限りで `effortLevel` 設定を上書きし、永続しない。 — [English](https://code.claude.com/docs/en/cli-reference#cli-flags)
- **/review の単発化と /code-review 追記**: コマンド一覧で `/review` の説明が更新された。`/review` は GitHub PR に対する高速な単発の読み取り専用レビューに戻り（v2.1.186〜2.1.201 は `/code-review medium` 相当だった）、多エージェントレビューは `/code-review <level> <pr#>`、クラウドは `/code-review ultra` と案内された。 — [commands](https://code.claude.com/docs/en/commands#commands-across-a-typical-workflow) / [commands](https://code.claude.com/docs/en/commands#all-commands)

### 🧰 拡張機能（プラグイン・スキル・フック） — 5件

- **プラグインのアンインストール範囲選択**: v2.1.203 で、プロジェクトの `.claude/settings.json` で有効化されたプラグインを削除する際、自分だけ無効化（`settings.local.json` に上書き）か全員向けにアンインストール（共有 `settings.json` から除去）かを選べるようになった。あわせて LSP サーバの稼働も「使用」として計上され、未使用プラグイン一覧の対象判定が変わった。 — [discover-plugins](https://code.claude.com/docs/en/discover-plugins#manage-installed-plugins) / [security-guidance](https://code.claude.com/docs/en/security-guidance#disable-or-uninstall)
- **プラグインルートの定義明確化**: プラグイン構造の説明に、プラグインルートは `.claude-plugin/plugin.json` を含む各プラグイン自身のディレクトリであり `~/.claude/` ではないことが明記された。例として `~/.claude/.mcp.json` は読まれない。 — [English](https://code.claude.com/docs/en/plugins#plugin-structure-overview)
- **設定リファレンス表への新キー追加**: 設定リファレンスの一覧表に多数のキーが追記・整理された。`advisorModel`・`agent`・`askUserQuestionTimeout`・`autoMode`（および `autoMode.classifyAllShell`）・`allowManaged*` 系の管理者向け制限・`channelsEnabled` など、advisor やチャンネル、管理設定まわりの項目が含まれる。 — [English](https://code.claude.com/docs/en/settings#settings-files)
- **ネストスキルの非修飾名解決**: v2.1.203 で、非修飾名でスキルを起動すると、プロジェクトルートのスキルが読み込まれつつ、ディレクトリ修飾された各バリアントの一覧と「作業中ファイルのあるディレクトリのバリアントも起動せよ」という指示が付与されるようになった。ネストスキルが非修飾起動でも当該ディレクトリの作業に適用される。 — [English](https://code.claude.com/docs/en/skills#getting-started)
- **プラグイン変数と roots/list 追記**: プラグインリファレンスで、`${CLAUDE_PROJECT_DIR}` の説明が整理され、MCP サーバが実行時に `roots/list` でセッションの作業ディレクトリ群を読める旨と参照先リンクが追記された。 — [English](https://code.claude.com/docs/en/plugins-reference#plugin-manifest-schema)
