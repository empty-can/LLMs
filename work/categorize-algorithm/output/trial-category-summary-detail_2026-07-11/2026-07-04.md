- **プロバイダ名称の一斉統一**: クラウドプロバイダ名の表記が約150ページ横断で一斉に統一された。Google Vertex AI は正式名称の「Google Cloud's Agent Platform（旧 Vertex AI）」へ、「Bedrock」は「Amazon Bedrock」へ、「Foundry」は「Microsoft Foundry」へ改称された。あくまで表記の改称であり、環境変数（CLAUDE_CODE_USE_VERTEX・ANTHROPIC_VERTEX_*・VERTEX_REGION_* 等）や CLI フラグ・ログイン画面のラベルは従来の VERTEX/BEDROCK 綴りを維持するため、機能・設定・挙動に変更はない。 — [admin-setup](https://code.claude.com/docs/en/admin-setup) / [admin-setup](https://code.claude.com/docs/en/admin-setup#choose-your-api-provider) / [admin-setup](https://code.claude.com/docs/en/admin-setup#decide-how-settings-reach-devices) ほか145箇所
- **コードブロック注記の重複除去**: Advanced setup のインストール手順で、コードブロックに重複付与されていた theme={null} 注記が1つに整理された。表示上の書式修正であり、内容の変更はない。 — [English](https://code.claude.com/docs/en/setup#install-claude-code)
