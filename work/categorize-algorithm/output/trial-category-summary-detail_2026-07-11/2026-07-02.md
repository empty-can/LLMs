- **Rewind file changes with checkpointing › Implement checkpointing**: Agent SDK のファイルチェックポインティングの実装例に補足が加えられた。認証モジュールを含むプロジェクトで実行する（または存在するファイル名にプロンプトを変える）とファイル変更と巻き戻しを確認しやすいこと、CLI からの巻き戻しには SDK パッケージには含まれない `claude` 実行ファイルが必要なことが追記された。 — [English](https://code.claude.com/docs/en/agent-sdk/file-checkpointing#implement-checkpointing)
- **Todo Lists › Examples**: Todo Lists の Examples に、実行前に quickstart に従って Claude Agent SDK をインストールしておく前提が追記された。 — [English](https://code.claude.com/docs/en/agent-sdk/todo-tracking#examples)
