## カテゴリ別の変更点

### ⌨️ コマンド — 1件

- **claude mcp add の短縮フラグ**: `claude mcp add` のフラグ説明に短縮形が追記された。`--scope` は `-s`、`--env` は `-e`、`--transport` は `-t`、`--header` は `-H` でも指定できることが明示された。 — [English](https://code.claude.com/docs/en/mcp#installing-mcp-servers)

### 🧰 拡張機能（プラグイン・スキル・フック） — 3件

- **プラグイン同梱 MCP のスコープ名**: プラグインが同梱する MCP サーバーは、ツールが `mcp__plugin_<plugin-name>_<server-name>__<tool>`、サーバー自体が `plugin:<plugin-name>:<server-name>` というスコープ付きの名前で登録されることが明記された。素のサーバー名で書いたマッチャーはこれらのツールに一致しないため、フックの matcher・`if` フィールド・`mcp_tool` フックの `server` フィールドにはスコープ付きの名前を使う必要がある。この注意書きがフックガイド・フックリファレンス・MCP・プラグインリファレンスの各ページに追加された。 — [hooks-guide](https://code.claude.com/docs/en/hooks-guide#how-hooks-work) / [mcp](https://code.claude.com/docs/en/mcp#installing-mcp-servers) / [hooks](https://code.claude.com/docs/en/hooks#configuration) ほか1箇所
- **フックのサブエージェント識別子拡張**: Python SDK で `agent_id` / `agent_type` を参照できるフックの範囲が広がった。従来の `PreToolUse` / `PostToolUse` / `PostToolUseFailure` に加え `PermissionRequest` でも任意フィールドとして利用でき、`SubagentStart` / `SubagentStop` では必須フィールドになったと記載された。 — [agent-sdk/hooks](https://code.claude.com/docs/en/agent-sdk/hooks#configure-hooks) / [agent-sdk/python](https://code.claude.com/docs/en/agent-sdk/python#hook-types)
- **transcript 遅延と last_assistant_message**: `transcript_path` が指す transcript ファイルは非同期に書き込まれるため、フック発火時点で現在のターンの最新メッセージを含まない場合があると明記された。直前のターンの最終応答テキストを必要とするフックは transcript を読まず、Stop / SubagentStop の `last_assistant_message` フィールドを使うよう推奨が追加された。 — [hooks](https://code.claude.com/docs/en/hooks#hook-input-and-output) / [hooks](https://code.claude.com/docs/en/hooks#hook-events)

### 🔐 パーミッション・セキュリティ — 2件

- **auto モードの Python SDK 対応**: パーミッションモード `auto`（モデル分類器がツール呼び出しごとに許可・拒否を判定する）に付いていた「TypeScript only」の注記が、エージェントループ・パーミッション・クイックスタートの各ページから削除された。Python SDK の `PermissionMode` にも `"auto"` が追加され、Python でも auto モードを指定できるようになった。 — [agent-sdk/agent-loop](https://code.claude.com/docs/en/agent-sdk/agent-loop#control-how-the-loop-runs) / [agent-sdk/permissions](https://code.claude.com/docs/en/agent-sdk/permissions#permission-modes) / [agent-sdk/python](https://code.claude.com/docs/en/agent-sdk/python#types) ほか1箇所
- **Python 承認コールバックの成立条件**: Python で `can_use_tool` を使うための条件の説明が詳細化された。`query(prompt=generator)` や `ClaudeSDKClient.connect(prompt=async_iterable)` で有限のメッセージストリームを渡すと、フックや in-process MCP サーバーがストリームを開いたままにしていない限り、パーミッションコールバックが呼ばれる前に入力ストリームが閉じられる。一方、プロンプトなしで接続し `ClaudeSDKClient.query()` でメッセージを送る場合はストリームが開いたままになり、フックは不要と明記された。 — [English](https://code.claude.com/docs/en/agent-sdk/user-input#handle-tool-approval-requests)
