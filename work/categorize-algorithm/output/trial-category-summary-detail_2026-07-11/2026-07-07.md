### 🧩 Agent SDK — 5件

- **auto権限モードのTS限定解除**: Agent SDK の auto パーミッションモード（モデル分類器がツール呼び出しごとに承認/拒否する）から「TypeScript only」の注記が外され、Python SDK でも利用可能になった。agent-loop・permissions・Python 型定義・quickstart の各モード表に反映された。 — [agent-sdk/agent-loop](https://code.claude.com/docs/en/agent-sdk/agent-loop#control-how-the-loop-runs) / [agent-sdk/permissions](https://code.claude.com/docs/en/agent-sdk/permissions#permission-modes) / [agent-sdk/python](https://code.claude.com/docs/en/agent-sdk/python#types) ほか1箇所

- **カスタムツールのエラーはループを止めない**: カスタムツールのハンドラが未捕捉例外を投げても Agent loop は停止せず、SDK の in-process MCP サーバが例外を捕捉しエラー結果として Claude に返すことが明確化された。isError: true を返す意義は、ループ継続のためではなく Claude が読むエラーメッセージを文脈付きで自分で構成するためだと位置づけが改められた。 — [agent-sdk/custom-tools](https://code.claude.com/docs/en/agent-sdk/custom-tools#quick-reference) / [agent-sdk/custom-tools](https://code.claude.com/docs/en/agent-sdk/custom-tools#handle-errors)
- **ツール結果の音声/バイナリのTS・Python差**: ツール結果の content ブロックのうち、音声ブロックは TypeScript ではディスク保存してパスをテキストで渡すが Python では破棄され警告ログが出る点、resource.blob のバイナリリソースも TypeScript のみ対応で Python では破棄される点が明記された。 — [English](https://code.claude.com/docs/en/agent-sdk/custom-tools#return-images-and-resources)
- **Pythonのcan_use_toolとストリーム維持条件**: Python の can_use_tool はストリーミングモードを要し、有限メッセージストリームを渡すと権限コールバック呼び出し前に入力ストリームが閉じるため、`{"continue_": True}` を返す PreToolUse フックか in-process MCP サーバで開いたままにする必要があると説明が具体化された。プロンプト無しで接続し ClaudeSDKClient.query() で送る場合はフック不要と補足された。 — [English](https://code.claude.com/docs/en/agent-sdk/user-input#handle-tool-approval-requests)
