## カテゴリ別の変更点

### 🧰 拡張機能（プラグイン・スキル・フック） — 1件

- **スキルのシンボリックリンク対応**: エンタープライズ・個人・プロジェクトの各配置で `<skill-name>` エントリをディスク上の別ディレクトリへのシンボリックリンクにできることが明記された。Claude Code はリンクを辿ってリンク先の `SKILL.md` を読み、同じリンク先が複数の配置から辿れる場合でもスキルは 1 回だけ読み込まれる。プラグインのスキルはシンボリックリンクの扱いが異なる。 — [English](https://code.claude.com/docs/en/skills#getting-started)

### 🔐 パーミッション・セキュリティ — 1件

- **チームメイト経由の権限迂回防止**: `SendMessage` で届いたメッセージは受信側エージェントに「別の Claude セッション由来」として伝えられ、チームメイトがユーザーの代わりに許可プロンプトを承認したり同意を与えたりはできないこと、拒否された操作を別のチームメイト経由で中継してチェックを回避することもできないことが明記された。auto mode では他エージェントから中継された承認の申告は信頼できない入力として扱われ、チームメイトの許可プロンプトはリードセッションに上がるため、そこで自分で承認する必要がある。 — [English](https://code.claude.com/docs/en/agent-teams#how-agent-teams-work)

### 📚 セッション・コンテキスト — 1件

- **Artifacts のベータ表記削除**: Artifacts の説明から「ベータ」の記載が削除された。Team または Enterprise プランと `/login` でサインインしたセッションが必要である点は従来どおり。 — [English](https://code.claude.com/docs/en/artifacts)

### 🤝 サブエージェント — 2件

- **チームメイト経由の権限迂回防止**: `SendMessage` で届いたメッセージは受信側エージェントに「別の Claude セッション由来」として伝えられ、チームメイトがユーザーの代わりに許可プロンプトを承認したり同意を与えたりはできないこと、拒否された操作を別のチームメイト経由で中継してチェックを回避することもできないことが明記された。auto mode では他エージェントから中継された承認の申告は信頼できない入力として扱われ、チームメイトの許可プロンプトはリードセッションに上がるため、そこで自分で承認する必要がある。 — [English](https://code.claude.com/docs/en/agent-teams#how-agent-teams-work)
- **セッション派遣先ディレクトリの指定拡張**: agent view で `@<repo>` を入力したときに列挙される対象が、起動ディレクトリの 1 階層下にある git リポジトリに加えて、既にセッションが一覧に存在するディレクトリも含むよう更新された。名前に空白を含むディレクトリは列挙されない旨も追記された。 — [English](https://code.claude.com/docs/en/agent-view#dispatch-new-agents)

### ⚙️ 設定・環境変数 — 2件

- **IDE 拡張の自動インストール抑止**: VS Code の統合ターミナルで `claude` を実行すると IDE 拡張が自動的に再インストールされることが明記され、アンインストール状態を保つ手順が追加された。`/config` の **Auto-install IDE extension** を無効にするか `autoInstallIdeExtension` を `false` にすればよく、環境変数 `CLAUDE_CODE_IDE_SKIP_AUTO_INSTALL` は値 `1` を設定する旨が明確化された。 — [settings](https://code.claude.com/docs/en/settings#settings-files) / [vs-code](https://code.claude.com/docs/en/vs-code#uninstall-the-extension)
- **シェル指定環境変数の説明刷新**: `CLAUDE_CODE_SHELL` の説明が刷新され、Bash ツールのコマンド実行に使うシェルとして `bash` または `zsh` バイナリのパス（例: `/opt/homebrew/bin/bash`）を指定するものであり、`fish` などは非対応であることが明記された。値が有効な `bash`/`zsh` のパスでない場合は無視され、`$SHELL` が bash/zsh ならそれを、そうでなければ `PATH` と標準インストール先から見つかった `zsh`・`bash` の順で自動検出する挙動も追記された。`CLAUDE_CODE_IDE_SKIP_AUTO_INSTALL` は `1` を設定する旨が明確化された。 — [English](https://code.claude.com/docs/en/env-vars#variables)

### 🖥 アプリ・プラットフォーム — 2件

- **IDE 拡張の自動インストール抑止**: VS Code の統合ターミナルで `claude` を実行すると IDE 拡張が自動的に再インストールされることが明記され、アンインストール状態を保つ手順が追加された。`/config` の **Auto-install IDE extension** を無効にするか `autoInstallIdeExtension` を `false` にすればよく、環境変数 `CLAUDE_CODE_IDE_SKIP_AUTO_INSTALL` は値 `1` を設定する旨が明確化された。 — [settings](https://code.claude.com/docs/en/settings#settings-files) / [vs-code](https://code.claude.com/docs/en/vs-code#uninstall-the-extension)
- **Windows でのインストールコマンド誤りの対処**: Windows PowerShell で macOS/Linux 向けの `curl -fsSL ... | bash` インストーラを実行すると、`curl` が `Invoke-WebRequest` のエイリアスであるため `A parameter cannot be found that matches parameter name 'fsSL'` エラーになることが説明され、エラー早見表にも追加された。対処として PowerShell 用インストーラ `irm https://claude.ai/install.ps1 | iex` を使う旨が示された。 — [troubleshoot-install](https://code.claude.com/docs/en/troubleshoot-install#find-your-error) / [troubleshoot-install](https://code.claude.com/docs/en/troubleshoot-install#common-installation-issues)

### 🤖 モデル・利用状況 — 4件

- **ゲートウェイ検出モデルの重複排除**: Claude Code v2.1.197 以降、ゲートウェイから検出した明示的なモデル ID が、同じモデルに解決される組み込みエントリへ折りたたまれるようになった。組み込み行は `sonnet` などのエイリアスをキーとするため、エイリアスの現在の解決先である `claude-sonnet-5` を検出した場合は `sonnet` 行に統合され、解決先が異なる `claude-sonnet-4-6` は従来どおり別の「From gateway」行として追加される。 — [English](https://code.claude.com/docs/en/llm-gateway-protocol#model-discovery)
- **advisor 許容モデルの注記追加**: advisor として指定できるモデルの対応表に、メインモデルが Opus 4.6 の場合は Sonnet 5 の advisor も受け付けるという注記が追加された。 — [English](https://code.claude.com/docs/en/advisor#choose-an-advisor-model)
- **xhigh 推奨モデルに Sonnet 5 追加**: Agent SDK の effort レベル表で、`"xhigh"` が推奨されるモデルとして Fable 5・Opus 4.7 以降に加えて Sonnet 5 が明記された。 — [English](https://code.claude.com/docs/en/agent-sdk/agent-loop#control-how-the-loop-runs)
- **ModelInfo 型のフィールド追加**: TypeScript SDK の ModelInfo 型に `resolvedModel` と `supportsAutoMode` が追加され、各フィールドの説明表が新設された。`resolvedModel` は `sonnet` などのエイリアスエントリが解決する正規のモデル ID（例: `claude-sonnet-5`）を示し、ホストが保存済みの明示的モデル ID をエイリアスエントリに突き合わせられるようにする（Claude Code v2.1.197 以降が必要）。 — [English](https://code.claude.com/docs/en/agent-sdk/typescript#other-types)

### 🧩 Agent SDK — 2件
