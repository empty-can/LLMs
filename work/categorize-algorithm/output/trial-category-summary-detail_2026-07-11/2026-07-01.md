## カテゴリ別の変更点

### 🧰 拡張機能（プラグイン・スキル・フック） — 1件

- **スキルの symlink 対応明記**: スキルの <skill-name> エントリが別の場所のディレクトリへの symlink でよいことが明記された。Claude Code は symlink をたどって対象ディレクトリの SKILL.md を読み、同一ターゲットが複数の場所から辿れても一度だけロードする。プラグインのスキルは symlink を別扱いする。 — [English](https://code.claude.com/docs/en/skills#getting-started)

### 🔐 パーミッション・セキュリティ — 1件

- **teammate による権限承認の禁止**: エージェント間メッセージ（SendMessage）で受信側は送信元を別 Claude セッションと認識し、teammate は権限プロンプトの承認や同意の代行ができず、拒否されたアクションを別 teammate に中継してチェックを回避することもできないと明記された。auto mode では他エージェントから中継された承認主張を信頼できない入力として扱い、teammate の権限プロンプトはリードセッションで各自承認する必要がある。 — [English](https://code.claude.com/docs/en/agent-teams#how-agent-teams-work)

### 📚 セッション・コンテキスト — 2件

- **@<repo> のディレクトリ指定挙動の明確化**: agent view から新規セッションを別ディレクトリで動かす際の @<repo> 指定挙動が更新された。@ を入力すると起動ディレクトリの 1 階層下の git リポジトリと、既にセッションが一覧にあるディレクトリが表示され、空白を含む名前のディレクトリは一覧に出ないことが明記された。 — [English](https://code.claude.com/docs/en/agent-view#dispatch-new-agents)
- **Artifacts のベータ表記削除**: Artifacts の説明から「ベータ」の表記が削除された。Team または Enterprise プランと /login 済みセッションという要件自体は変わらない。 — [English](https://code.claude.com/docs/en/artifacts)

### 🤝 サブエージェント — 2件

- **teammate による権限承認の禁止**: エージェント間メッセージ（SendMessage）で受信側は送信元を別 Claude セッションと認識し、teammate は権限プロンプトの承認や同意の代行ができず、拒否されたアクションを別 teammate に中継してチェックを回避することもできないと明記された。auto mode では他エージェントから中継された承認主張を信頼できない入力として扱い、teammate の権限プロンプトはリードセッションで各自承認する必要がある。 — [English](https://code.claude.com/docs/en/agent-teams#how-agent-teams-work)
- **@<repo> のディレクトリ指定挙動の明確化**: agent view から新規セッションを別ディレクトリで動かす際の @<repo> 指定挙動が更新された。@ を入力すると起動ディレクトリの 1 階層下の git リポジトリと、既にセッションが一覧にあるディレクトリが表示され、空白を含む名前のディレクトリは一覧に出ないことが明記された。 — [English](https://code.claude.com/docs/en/agent-view#dispatch-new-agents)

### ⚙️ 設定・環境変数 — 3件

- **IDE拡張自動導入のスキップ設定追記**: 設定 autoInstallIdeExtension の説明が更新され、環境変数 CLAUDE_CODE_IDE_SKIP_AUTO_INSTALL を 1 に設定すると自動導入を無効化できることが明記された。 — [English](https://code.claude.com/docs/en/settings#settings-files)
- **IDE拡張の自動再インストール無効化手順**: VS Code 統合ターミナルで claude を実行すると拡張が自動で再インストールされることが明記された。無効のまま保つには /config の Auto-install IDE extension をオフにするか、autoInstallIdeExtension を false、または CLAUDE_CODE_IDE_SKIP_AUTO_INSTALL を 1 に設定するよう案内された。 — [English](https://code.claude.com/docs/en/vs-code#uninstall-the-extension)
- **環境変数の追加・記述更新**: 環境変数の記述が更新された。CLAUDE_CODE_IDE_SKIP_AUTO_INSTALL は 1 を設定する旨が明確化され、CLAUDE_CODE_SHELL は bash/zsh のパス指定とフォールバックの自動検出挙動が詳述された。加えて Vertex AI で Sonnet 5 のリージョンを上書きする VERTEX_REGION_CLAUDE_5_SONNET が v2.1.197 で追加された。 — [English](https://code.claude.com/docs/en/env-vars#variables)

### 🖥 アプリ・プラットフォーム — 3件

- **IDE拡張自動導入のスキップ設定追記**: 設定 autoInstallIdeExtension の説明が更新され、環境変数 CLAUDE_CODE_IDE_SKIP_AUTO_INSTALL を 1 に設定すると自動導入を無効化できることが明記された。 — [English](https://code.claude.com/docs/en/settings#settings-files)
- **Windows 誤インストール時の fsSL エラー案内**: Windows で macOS/Linux 用の curl -fsSL ... | bash を実行した際に出る「A parameter cannot be found that matches parameter name 'fsSL'」エラーがトラブルシュートに追加された。原因は PowerShell の curl が Invoke-WebRequest のエイリアスで -fsSL を受け付けないためで、代わりに irm https://claude.ai/install.ps1 | iex を使うよう案内された。 — [troubleshoot-install](https://code.claude.com/docs/en/troubleshoot-install#find-your-error) / [troubleshoot-install](https://code.claude.com/docs/en/troubleshoot-install#common-installation-issues)
- **IDE拡張の自動再インストール無効化手順**: VS Code 統合ターミナルで claude を実行すると拡張が自動で再インストールされることが明記された。無効のまま保つには /config の Auto-install IDE extension をオフにするか、autoInstallIdeExtension を false、または CLAUDE_CODE_IDE_SKIP_AUTO_INSTALL を 1 に設定するよう案内された。 — [English](https://code.claude.com/docs/en/vs-code#uninstall-the-extension)

### 🤖 モデル・利用状況 — 5件

- **検出モデルIDの組み込み行への畳み込み**: ゲートウェイで検出したモデル ID の重複判定が拡張された。v2.1.197 以降、検出した明示 ID がエイリアス（例 sonnet）の現行解決先と一致する場合は組み込み行に畳み込まれ、エイリアスが解決しない ID（例 claude-sonnet-4-6）は従来どおり別の「From gateway」行として追加される。 — [English](https://code.claude.com/docs/en/llm-gateway-protocol#model-discovery)
- **advisor モデル受理条件の追記**: advisor のメイン／受理モデル対応表に注記が追加され、Opus 4.6 をメインにした場合は Sonnet 5 も advisor として受理できることが明記された。 — [English](https://code.claude.com/docs/en/advisor#choose-an-advisor-model)
- **xhigh 推奨に Sonnet 5 追加**: Agent SDK のエフォート水準表で、xhigh の推奨対象に Sonnet 5 が追加された（従来は Fable 5 と Opus 4.7+）。 — [English](https://code.claude.com/docs/en/agent-sdk/agent-loop#control-how-the-loop-runs)
- **モデル型に resolvedModel/autoMode 追加**: TypeScript Agent SDK のモデル情報型に resolvedModel と supportsAutoMode フィールドが追加された。resolvedModel はエイリアスエントリ（例 sonnet）が解決する正規のワイヤモデル ID を示し（v2.1.197 以降）、supportsAutoMode は auto mode 対応可否を表す。 — [English](https://code.claude.com/docs/en/agent-sdk/typescript#other-types)
- **Vertex の WebSearch 対応モデル拡大**: WebSearch ツールの提供状況が更新され、Google Cloud Vertex AI では Claude 4 だけでなく Claude 4 以降のモデル（Opus・Sonnet・Haiku）で利用できると明記された。Amazon Bedrock は引き続きサーバーサイドの Web 検索ツールを提供しない。 — [English](https://code.claude.com/docs/en/tools-reference#websearch-tool-behavior)
