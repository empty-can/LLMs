## カテゴリ別の変更点

### 🔐 パーミッション・セキュリティ — 1件

- **Orchestrate teams of Claude Code sessions › How agent teams work**: エージェント間の SendMessage 経由のメッセージは別 Claude セッション由来として受信側に伝えられ、チームメイトが代理でパーミッションを承認したり同意を与えたりはできず、拒否されたアクションを別のチームメイトに中継してチェックを回避することもできないと明記された。auto モードでは他エージェントから中継された承認の主張を信頼できない入力として扱い、チームメイトのパーミッションプロンプトはリードセッションにバブルアップするため、そこで各自承認すべきと追記された。 — [English](https://code.claude.com/docs/en/agent-teams#how-agent-teams-work)

### 🧰 拡張機能（プラグイン・スキル・フック） — 1件

- **Extend Claude with skills › Getting started**: スキルの `<skill-name>` エントリがディスク上の別ディレクトリへのシンボリックリンクでもよくなり、Claude Code はリンクをたどって対象ディレクトリの `SKILL.md` を読み込むこと、同一対象が複数の場所から到達可能でもスキルは一度だけロードされることが明記された。プラグインスキルはシンボリックリンクを別扱いする旨も追記された。 — [English](https://code.claude.com/docs/en/skills#getting-started)

### 🧩 Agent SDK・サブエージェント — 4件

- **Orchestrate teams of Claude Code sessions › How agent teams work**: エージェント間の SendMessage 経由のメッセージは別 Claude セッション由来として受信側に伝えられ、チームメイトが代理でパーミッションを承認したり同意を与えたりはできず、拒否されたアクションを別のチームメイトに中継してチェックを回避することもできないと明記された。auto モードでは他エージェントから中継された承認の主張を信頼できない入力として扱い、チームメイトのパーミッションプロンプトはリードセッションにバブルアップするため、そこで各自承認すべきと追記された。 — [English](https://code.claude.com/docs/en/agent-teams#how-agent-teams-work)
- **Manage multiple agents with agent view › Dispatch new agents**: agent view で新規セッションを別ディレクトリに向ける方法が拡充され、`@<repo>` の入力で起動ディレクトリの1階層下の git リポジトリと、既にセッションを持つディレクトリが一覧されるようになった旨が明記された。名前に空白を含むディレクトリは一覧されないと追記された。 — [English](https://code.claude.com/docs/en/agent-view#dispatch-new-agents)
- **How the agent loop works › Control how the loop runs**: エージェントループの effort レベル表で、`xhigh` の推奨対象に従来の Fable 5・Opus 4.7+ に加えて Sonnet 5 が追加された。 — [English](https://code.claude.com/docs/en/agent-sdk/agent-loop#control-how-the-loop-runs)
- **Agent SDK reference - TypeScript › Other Types**: TypeScript Agent SDK のモデル型に、エイリアスエントリが解決する正規のワイヤモデル ID を示す `resolvedModel`（v2.1.197 以降）と、モデルが auto モードに対応するかを示す `supportsAutoMode` フィールドが追加された。 — [English](https://code.claude.com/docs/en/agent-sdk/typescript#other-types)

### ⚙️ 設定・環境変数 — 3件

- **Claude Code settings › Settings files**: `autoInstallIdeExtension` 設定の説明に、環境変数 `CLAUDE_CODE_IDE_SKIP_AUTO_INSTALL` を `1` に設定して自動インストールを抑止する方法が追記された。 — [English](https://code.claude.com/docs/en/settings#settings-files)
- **Use Claude Code in VS Code › Uninstall the extension**: VS Code 統合ターミナルで `claude` を実行すると拡張機能が自動的に再インストールされるため、アンインストール状態を保つには `/config` の Auto-install IDE extension を無効化するか、`autoInstallIdeExtension` を `false`、または `CLAUDE_CODE_IDE_SKIP_AUTO_INSTALL` を `1` に設定する必要がある旨が追記された。 — [English](https://code.claude.com/docs/en/vs-code#uninstall-the-extension)
- **Environment variables › Variables**: 環境変数リファレンスが更新され、`CLAUDE_CODE_IDE_SKIP_AUTO_INSTALL` の説明が整理されたほか、`CLAUDE_CODE_SHELL` に bash/zsh バイナリのパス指定・非対応シェルの扱い・無効値時の自動検出フォールバックの詳細が追記された。さらに Vertex AI 利用時に Claude Sonnet 5 のリージョンを上書きする `VERTEX_REGION_CLAUDE_5_SONNET`（v2.1.197 追加）が新設された。 — [English](https://code.claude.com/docs/en/env-vars#variables)

### 🤖 モデル・利用状況 — 6件

- **Gateway protocol reference › Model discovery**: ゲートウェイのモデルディスカバリで、Claude Code v2.1.197 以降、発見された明示的 ID がエイリアスの現在の解決先と同一モデルに解決される場合は組み込み行に統合されるようになった。エイリアス（例 `sonnet`）が解決する ID（例 `claude-sonnet-5`）は `sonnet` 行に折り畳まれ、解決しない ID（例 `claude-sonnet-4-6`）は従来どおり独自の "From gateway" 行を追加すると明記された。 — [English](https://code.claude.com/docs/en/llm-gateway-protocol#model-discovery)
- **Monitoring › Available metrics and events**: 監視メトリクスの `model` フィールドの例示値が `claude-sonnet-4-6` から `claude-sonnet-5` に更新された。 — [English](https://code.claude.com/docs/en/monitoring-usage#available-metrics-and-events)
- **Escalate hard decisions with the advisor tool › Choose an advisor model**: advisor のメインモデル別・受理可能アドバイザー表の注記が拡充され、Opus 4.6 以降をメインとする場合に Sonnet 5 アドバイザーも受理される例が明示された。 — [English](https://code.claude.com/docs/en/advisor#choose-an-advisor-model)
- **How the agent loop works › Control how the loop runs**: エージェントループの effort レベル表で、`xhigh` の推奨対象に従来の Fable 5・Opus 4.7+ に加えて Sonnet 5 が追加された。 — [English](https://code.claude.com/docs/en/agent-sdk/agent-loop#control-how-the-loop-runs)

- **Tools reference › WebSearch tool behavior**: WebSearch ツールの提供状況で、Google Cloud Vertex AI の対応範囲が「Claude 4 モデル」から「Claude 4 以降のモデル」に拡張された（Opus・Sonnet・Haiku を含む）。Amazon Bedrock がサーバーサイド Web 検索ツールを提供しない点は変わらない。 — [English](https://code.claude.com/docs/en/tools-reference#websearch-tool-behavior)
