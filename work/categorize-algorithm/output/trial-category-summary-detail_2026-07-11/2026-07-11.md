## カテゴリ別の変更点

### 🔐 パーミッション・セキュリティ — 2件

- **デフォルト/手動モードの承認範囲の明確化**: デフォルト設定および VS Code の Manual モードの説明が「各アクションごとに確認」から「ファイル編集とほとんどのシェルコマンドの前に確認」へ改められた。読み取り専用コマンドが確認を挟まず動くことが文言に反映され、いつ確認が入るかの理解が具体化された。 — [communications-kit](https://code.claude.com/docs/en/communications-kit#tips-and-tricks-campaign) / [vs-code](https://code.claude.com/docs/en/vs-code#use-the-prompt-box)
- **read-only コマンドと作業ディレクトリ境界の明文化**: 組み込みの読み取り専用シェルコマンド（ls・cat・git status 等）が確認なしで実行されること、作業ディレクトリ（および追加ディレクトリ）の外を Read/Grep/Glob で読む際は承認プロンプトが入ること、sandbox の denyRead ルールで読み取り範囲を絞れることが、権限システム表・セキュリティ・ツールリファレンス・コミュニケーションキットの各所で追記・整理された。権限モデルの挙動がページ横断で具体的に説明されるようになった。 — [communications-kit](https://code.claude.com/docs/en/communications-kit#quick-reference) / [permissions](https://code.claude.com/docs/en/permissions#permission-system) / [security](https://code.claude.com/docs/en/security#how-we-approach-security) ほか1箇所

### 🖥 アプリ・プラットフォーム — 2件

- **Linux 版 .deb の apt プール直接取得手順**: apt リポジトリからインストールできない場合に、リポジトリのパッケージプールから最新の `.deb` を curl で直接ダウンロードする手順が追加された。`Remote file name has no length` エラー時の対処（ネットワークが downloads.claude.ai に到達できるか、アーキが amd64/arm64 か確認）も示され、この方法で入れた `.deb` は自動更新されない旨が明記された。 — [English](https://code.claude.com/docs/en/desktop-linux#install)
- **Linux デスクトップ導線を apt 案内へ変更**: Advanced setup とインストールのトラブルシュートで、Linux 版デスクトップアプリの入手先が `claude.com/download` の直接ダウンロードから、apt でインストールする desktop-linux ページの案内へ変更された。macOS/Windows のリンクは従来どおり。 — [setup](https://code.claude.com/docs/en/setup#install-claude-code) / [troubleshoot-install](https://code.claude.com/docs/en/troubleshoot-install#find-your-error)

### 🔌 MCP・外部連携 — 1件

- **SDK の MCP 出力上限と警告の関連リンク追加**: MCP 連携ページの関連リソースに「MCP output limits and warnings」への導線が追加された。`MAX_MCP_OUTPUT_TOKENS` 超過時に SDK がとるディスク退避フォールバックや、`anthropic/maxResultSizeChars` によるツール単位の上限指定について案内される。 — [English](https://code.claude.com/docs/en/agent-sdk/mcp#related-resources)

### 🧩 Agent SDK — 1件

- **SDK の MCP 出力上限と警告の関連リンク追加**: MCP 連携ページの関連リソースに「MCP output limits and warnings」への導線が追加された。`MAX_MCP_OUTPUT_TOKENS` 超過時に SDK がとるディスク退避フォールバックや、`anthropic/maxResultSizeChars` によるツール単位の上限指定について案内される。 — [English](https://code.claude.com/docs/en/agent-sdk/mcp#related-resources)
