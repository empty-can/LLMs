## カテゴリ別の変更点

### 🔐 パーミッション・セキュリティ — 2件

- **読み取り承認範囲の明確化**: 承認プロンプトの対象範囲が各ドキュメントで明確化された。`ls` / `cat` / `git status` などの組み込みの読み取り専用シェルコマンドはプロンプトなしで実行され、それ以外のシェルコマンドとファイル編集は従来どおり承認が必要であることが明記された。あわせて、Read / Grep / Glob による作業ディレクトリおよび追加ディレクトリの外側のパスの読み取りは承認プロンプトの対象であること、読み取り専用シェルコマンドの広い読み取りはサンドボックス有効時の `denyRead` ルールで制限できることが追記された。 — [communications-kit](https://code.claude.com/docs/en/communications-kit#quick-reference) / [permissions](https://code.claude.com/docs/en/permissions#permission-system) / [security](https://code.claude.com/docs/en/security#how-we-approach-security) ほか1箇所
- **パーミッションモード説明の精緻化**: デフォルトのパーミッションモード（VS Code 上の表記は Manual）の説明が「各アクションの前に確認する」から「ファイル編集とほとんどのシェルコマンドの前に確認する」へ改められた。読み取り専用コマンドが確認対象外であることがモードの説明文にも反映された。 — [communications-kit](https://code.claude.com/docs/en/communications-kit#tips-and-tricks-campaign) / [vs-code](https://code.claude.com/docs/en/vs-code#use-the-prompt-box)

### 🖥 アプリ・プラットフォーム — 2件

- **Linux 版 .deb 直接取得手順**: apt リポジトリを使えない場合の `.deb` 直接インストール手順が刷新された。claude.com/download からの取得ではなく、リポジトリのパッケージインデックスから自アーキテクチャ向けの最新パッケージを検索して curl で取得するコマンドが示された。`Remote file name has no length` エラー時の切り分け（downloads.claude.ai への到達性確認、公開されるのは amd64 / arm64 のみ）も追記された。 — [English](https://code.claude.com/docs/en/desktop-linux#install)
- **Linux デスクトップ導線の変更**: デスクトップアプリの Linux 向けダウンロード導線が claude.com/download から Linux インストール手順ページ（/docs/en/desktop-linux）へ張り替えられた。インストール／ログインのトラブルシュートページでは、Linux では apt でアプリをインストールする旨が明記された。 — [setup](https://code.claude.com/docs/en/setup#install-claude-code) / [troubleshoot-install](https://code.claude.com/docs/en/troubleshoot-install#find-your-error)

### 🔌 MCP・外部連携 — 1件

- **MCP 出力上限の参照追加**: Agent SDK の MCP ページの関連リソースに「MCP output limits and warnings」へのリンクが追加された。`MAX_MCP_OUTPUT_TOKENS` を超えるツール結果を SDK がどう扱うか（ディスクへ退避するフォールバック、`anthropic/maxResultSizeChars` のツール単位アノテーション）を参照できるようになった。 — [English](https://code.claude.com/docs/en/agent-sdk/mcp#related-resources)

### 🧩 Agent SDK — 1件

- **MCP 出力上限の参照追加**: Agent SDK の MCP ページの関連リソースに「MCP output limits and warnings」へのリンクが追加された。`MAX_MCP_OUTPUT_TOKENS` を超えるツール結果を SDK がどう扱うか（ディスクへ退避するフォールバック、`anthropic/maxResultSizeChars` のツール単位アノテーション）を参照できるようになった。 — [English](https://code.claude.com/docs/en/agent-sdk/mcp#related-resources)
