## カテゴリ別の変更点

### ⌨️ コマンド — 5件

- **v2.1.202 更新ログ追加**: インラインの `Ctrl+R` 履歴検索で走査中に確定・キャンセルするとクラッシュする不具合と、マイクや録音機能の失敗時に音声入力が無制限にリトライする不具合（繰り返し失敗した場合は音声入力を一時停止するよう変更）が修正された。`claude auth login` と `claude mcp login --no-browser` が表示するサインイン URL は、SSH 越しに折り返してもクリックできる単一のハイパーリンクとして出力されるようになった。`/review <pr>` は高速な単発レビューに戻され、複数エージェントによるレビューは `/code-review <level> <pr#>` を使う形になった。 — [English](https://code.claude.com/docs/en/changelog)
- **/review の単発レビュー回帰**: `/review <pr>` は `/code-review` と同じレビューエンジンを使う方式をやめ、セッションの effort による単発の読み取り専用レビューに戻った。コマンド一覧と ultrareview の比較表もこれに合わせて更新され、`/review` の深さは「単発レビュー」、所要時間は「数秒〜数分」と記載された。 — [ultrareview](https://code.claude.com/docs/en/ultrareview) / [ultrareview](https://code.claude.com/docs/en/ultrareview#how-ultrareview-compares-to-code-review-and-review) / [commands](https://code.claude.com/docs/en/commands#commands-across-a-typical-workflow) ほか1箇所
- **Esc のダイアログ優先動作**: パーミッションプロンプトなどのダイアログが開いているときの `Esc` は、Claude を中断せずにダイアログを閉じる動作になった。v2.1.202 より前は、一部のダイアログで `Esc` が Claude を中断しつつダイアログを開いたままにしていた。 — [English](https://code.claude.com/docs/en/interactive-mode#keyboard-shortcuts)
- **履歴検索の即時確定**: コマンド履歴の検索で、履歴の読み込み中でも一致の確定やキャンセルが即座に反映されるようになった。v2.1.202 より前は、読み込み中に確定・キャンセルすると内部エラーが報告されることがあった。 — [English](https://code.claude.com/docs/en/interactive-mode#command-history)
- **音声入力の失敗検知の拡大**: 音声入力を一時停止する連続失敗の判定に、マイクの起動失敗だけでなく、録音は始まったのに音声が生成されなかったケースも数えられるようになった。v2.1.202 より前は起動時の失敗のみが対象だった。 — [English](https://code.claude.com/docs/en/voice-dictation#troubleshooting)

### 🧰 拡張機能（プラグイン・スキル・フック） — 5件

- **v2.1.202 更新ログ追加**: 読み込み済みのスキルを再度呼び出すと、その指示文がコンテキストに二重に追加される不具合が修正された。 — [English](https://code.claude.com/docs/en/changelog)

- **GHES marketplace 追加失敗の対処**: claude.ai のユーザー設定から GHES の marketplace を追加して「Marketplace couldn't be added」のような一般的なエラーになる場合、自分の GitHub Enterprise アカウントが未接続であることが原因だとする節が追加された。claude.ai/code のリポジトリピッカーや Claude Code 管理設定の GitHub Enterprise セクションから接続するか、Owner に組織のプラグイン設定で追加してもらう対処が示された。 — [English](https://code.claude.com/docs/en/github-enterprise-server#troubleshooting)
- **スキル再呼び出しの重複防止**: 既にコンテキストにあるスキルを同じ内容で再度呼び出した場合、内容を再掲せず「読み込み済み」という短い注記だけが追加されるようになった。引数の変更や動的コンテキストの出力によって内容が変わる場合は、従来どおり全文が再度追加される。v2.1.202 より前は、再呼び出しのたびにスキルの指示文が丸ごと追加されていた。 — [English](https://code.claude.com/docs/en/skills#configure-skills)
- **非同期フックの JSON 検証**: バックグラウンド実行のフックが返す JSON も同期フックと同じ出力スキーマで検証され、型が誤ったフィールド（文字列でない `systemMessage` など）は配信されずに破棄されるようになった。`--debug` で実行すると破棄されたフィールド名が警告に出る。v2.1.202 より前は、非同期フックの不正な JSON でセッションがクラッシュし、再開のたびに同じクラッシュが起きていた。 — [English](https://code.claude.com/docs/en/hooks#run-hooks-in-the-background)

- **cd 判定とパス許可の厳密化**: `cd` と `git` を 1 つの複合コマンドにした場合の確認は、`cd` が別ディレクトリへ移動するときだけ発生するようになり（新しいディレクトリの hook が実行され得るため）、現在の作業ディレクトリに解決される `cd` は no-op として確認されなくなった。「Yes, don't ask again」でファイルパスを許可すると、`[`・`]`・`*` などの gitignore パターン文字がエスケープされ、生成された規則が許可した実際のパスだけに一致するようになった（自分で書いた規則はエスケープされない）。 — [English](https://code.claude.com/docs/en/permissions#tool-specific-permission-rules)
