### ⌨️ コマンド — 7件

- **ultrareview と /review の比較更新**: ultrareview のカバレッジ説明と、`/code-review`・`/review`・`/code-review ultra` の比較表が更新された。`/review` が `/code-review` エンジンではなくセッションの effort による単一パスのレビューとして位置づけ直され、対象・実行場所・深さ・所要時間・コストの整理が明確化された。 — [ultrareview](https://code.claude.com/docs/en/ultrareview) / [ultrareview](https://code.claude.com/docs/en/ultrareview#how-ultrareview-compares-to-code-review-and-review)
- **Esc キーのダイアログ挙動修正**: 権限プロンプトなどのダイアログが開いているときの `Esc` が、Claude を中断せずダイアログを閉じるようになった。v2.1.202 より前は一部ダイアログで `Esc` が Claude を中断し、ダイアログが開いたまま残っていた。 — [English](https://code.claude.com/docs/en/interactive-mode#keyboard-shortcuts)
- **履歴検索の読み込み中確定対応**: `Ctrl+R` の履歴検索で、履歴ファイルの読み込み中でもマッチの確定やキャンセルが即座に反映されるようになった。v2.1.202 より前はその読み込み中の確定・キャンセルで内部エラーになることがあった。 — [English](https://code.claude.com/docs/en/interactive-mode#command-history)
- **ScheduleWakeup の stop 対応とベンダー制限**: `ScheduleWakeup` ツールに、セルフペース `/loop` を終了させる `stop` フィールドが追加された（v2.1.202 以降）。Amazon Bedrock・Google Cloud の Agent Platform・Microsoft Foundry では利用できず、間隔なしの `/loop` は固定スケジュールで動作する点は従来どおり。 — [English](https://code.claude.com/docs/en/tools-reference)
- **/review と /security-review の説明更新**: コマンド一覧で `/review` が `/code-review` エンジンを使う説明から、GitHub プルリクエストを対象とする読み取り専用レビューへと記述が更新された。あわせて `/security-review` が差分のセキュリティ脆弱性を検査する旨に整理された。 — [commands](https://code.claude.com/docs/en/commands#commands-across-a-typical-workflow) / [commands](https://code.claude.com/docs/en/commands#all-commands)
