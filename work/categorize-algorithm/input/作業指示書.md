# 背景

日次で llms.txt や llms-full.txt の差分をサマライズしてもらっているが、現在ハイライトとしてピックアップされている差分が、想定読者である私（作業指示書）の所属する開発チームメンバーにとっては、特に重要でないトピックであることがある。  

これは各メンバーが担当している業務次第で、仕様改善・変更があったClaude Codeの機能を使っているかどうかが変わってくるためである。よって、各メンバーが、自身の業務に関係のある仕様差分の有無を素早く確認できるような構成のサマリを考える必要がある。

# 作業指示

* Phase1. 各メンバーが、自身の業務に関係のある仕様差分の有無を素早く確認できるようなサマライズの手法を、思いつく限り案を出してください。
* Phase2. 作業指示者と協議のうえ、採用する案について合意してください。
* Phase3. Phase2.で決定された各採用案に基づいたサマリファイル生成処理の設計行い、その内容について作業指示者と合意してください。
* Phase4. Phase3.の設計に基づいてサマリ生成のための実装を行ってください。
